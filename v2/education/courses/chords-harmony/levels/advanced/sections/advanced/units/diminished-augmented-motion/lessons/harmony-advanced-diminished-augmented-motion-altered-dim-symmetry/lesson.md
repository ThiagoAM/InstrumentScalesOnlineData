# Bdim7 / Ddim7を比べる

無音予測の回でBdim7 / Ddim7を1回読み、ピアノの2 ボイシングを4 拍保ち、低音B2 → D3と上声A♭3 → C♭4を追います。変化和音の対称性を「ディミニッシュは音程を縮め、オーギュメントは5度を広げます」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで2 ボイシングをすべて弾き、音域を変えずB2 → D3とA♭3 → C♭4を別々に歌って変化和音の対称性を確かめます。

無音予測の回で各記譜グループを戻し、一本の旋律としてではなく、低音シ2→レ3と上声ラ・フラット3→ド・フラット4を重点的に聴きます。低音シ2→レ3と上声ラ・フラット3→ド・フラット4を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。4 拍を止めずに2回録音し、B2 → D3とA♭3 → C♭4が記譜音域の各境界へ同時に着く場合だけ残します。最後に無音予測の回の変化和音の対称性を確認します。
