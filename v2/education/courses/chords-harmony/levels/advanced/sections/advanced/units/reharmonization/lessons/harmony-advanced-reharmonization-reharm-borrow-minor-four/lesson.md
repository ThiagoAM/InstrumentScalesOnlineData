上声優先の回でF–Fm–Cを1回読み、ピアノの3 ボイシングを6 拍保ち、低音F3 → F3 → C3と上声C4 → C4 → G3を追います。メロディーを保つ代理コードを「有効なリハーモナイズはメロディー音を支え、到着先を明確にし、効果が聞こえるよう一度に一要素だけ変えます」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで3 ボイシングをすべて弾き、音域を変えずF3 → F3 → C3とC4 → C4 → G3を別々に歌ってメロディーを保つ代理コードを確かめます。

上声優先の回で各記譜グループを戻し、一本の旋律としてではなく、低音ファ3→ド3と上声ド4→ソ3を重点的に聴きます。低音ファ3→ド3と上声ド4→ソ3を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。6 拍を止めずに2回録音し、F3 → F3 → C3とC4 → C4 → G3が記譜音域の各境界へ同時に着く場合だけ残します。最後に上声優先の回のメロディーを保つ代理コードを確認します。
