# G メロディー： C–Am–F–Gを保つ

再開しないテイクでG メロディー： C–Am–F–Gを1回読み、ピアノの4 ボイシングを8 拍保ち、低音C3 … G2と上声G4 … G4を追います。セクション間の対比を「コード変更の密度、カデンツの強さ、音域、調の中心が各セクションを分けると形式が聞こえます」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで4 ボイシングをすべて弾き、音域を変えずC3 … G2とG4 … G4を別々に歌ってセクション間の対比を確かめます。

再開しないテイクで各記譜グループを戻し、一本の旋律としてではなく、低音ファ3→ソ2と上声ソ4→ソ4を重点的に聴きます。低音ファ3→ソ2と上声ソ4→ソ4を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。8 拍を止めずに2回録音し、C3 … G2とG4 … G4が記譜音域の各境界へ同時に着く場合だけ残します。最後に再開しないテイクのセクション間の対比を確認します。

# 保持G 旋律位于 C–Am–F–G

在不重启录音中把G 旋律位于 C–Am–F–G读一遍；钢琴在8 拍内保持4 和弦排列，低音为C3 … G2，顶声部为G4 … G4。把段落对比与“当和弦变化密度、终止强度、音区与调性中心区分相邻段落时，曲式就能被听见”这个原理联系起来；方括号内各音同时开始，两条外声路线则揭示方向。以66 BPM弹完4 和弦排列，再保持音区不变，分别唱C3 … G2与G4 … G4来核对段落对比。

在不重启录音中恢复每个写出音组，重点聆听低音fa3→sol2与顶声部sol4→sol4，不要把和声听成一条被摊平的旋律。修正低音fa3→sol2与顶声部sol4→sol4时，只循环最后两个写出事件，直到两条外声连续两次同时到达。不中断地录下两遍8 拍；只有C3 … G2与G4 … G4都在写出音区同时到达每个边界时才保留。最后复核不重启录音中的段落对比。
