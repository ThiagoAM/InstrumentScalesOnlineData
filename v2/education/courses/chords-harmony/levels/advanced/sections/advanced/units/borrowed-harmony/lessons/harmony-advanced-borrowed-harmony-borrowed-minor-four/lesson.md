# Empreste C–Fm–C

Leia C–Fm–C uma vez na passagem das vozes externas; o piano sustenta 3 aberturas por 6 tempos, com baixo C3 → F3 → C3 e topo G3 → C4 → G3. Relacione grau emprestado a este princípio: A mistura modal altera graus escolhidos em um acorde; as notas entre colchetes começam juntas enquanto os caminhos externos revelam direção. Toque todas as 3 aberturas a 66 BPM e cante C3 → F3 → C3 e G3 → C4 → G3 separadamente para conferir grau emprestado sem mudar o registro.

Restaure cada grupo escrito durante a passagem das vozes externas e ouça especificamente baixo fá3 → dó3 e topo dó4 → sol3, não uma melodia única achatada. Corrija baixo fá3 → dó3 e topo dó4 → sol3 repetindo apenas os dois eventos finais até as duas vozes externas chegarem juntas duas vezes. Guarde duas tomadas contínuas de 6 tempos apenas quando C3 → F3 → C3 e G3 → C4 → G3 alcançarem cada fronteira juntos no registro escrito. Use grau emprestado como verificação final da passagem das vozes externas.

# Toma prestado C–Fm–C

Lee C–Fm–C una vez en la pasada de voces exteriores; el piano mantiene 3 disposiciones durante 6 pulsos, con bajo C3 → F3 → C3 y voz superior G3 → C4 → G3. Relaciona grado prestado con este principio: La mezcla modal altera grados concretos durante un acorde; las notas entre corchetes empiezan juntas mientras las líneas exteriores revelan dirección. Toca todas las 3 disposiciones a 66 BPM y canta C3 → F3 → C3 y G3 → C4 → G3 por separado para comprobar grado prestado sin cambiar de registro.

Corrige bajo fa3 → do3 y voz superior do4 → sol3 repitiendo solo los dos eventos finales hasta que ambas voces exteriores lleguen juntas dos veces. Conserva dos tomas continuas de 6 pulsos solo cuando C3 → F3 → C3 y G3 → C4 → G3 alcancen juntos cada límite en el registro escrito. Usa grado prestado como comprobación final de la pasada de voces exteriores.

# Entlehne C–Fm–C

Lies C–Fm–C einmal im Außenstimmendurchgang; das Klavier hält 3 Lagen über 6 Schläge, mit Bass C3 → F3 → C3 und Oberstimme G3 → C4 → G3. Verbinde entlehnte Stufe mit diesem Prinzip: Modaler Austausch verändert ausgewählte Stufen für einen Akkord; Klammernoten beginnen gemeinsam, während die Außenwege Richtung zeigen. Spiele alle 3 Lagen bei 66 BPM und singe C3 → F3 → C3 sowie G3 → C4 → G3 getrennt, um entlehnte Stufe ohne Lagenwechsel zu prüfen.

Stelle im Außenstimmendurchgang jede notierte Gruppe wieder her und höre gezielt auf Bass F3 → C3 und Oberstimme C4 → G3, nicht auf eine abgeflachte Einzelmelodie. Repariere Bass F3 → C3 und Oberstimme C4 → G3, indem du nur die letzten zwei Ereignisse wiederholst, bis beide Außenstimmen zweimal gemeinsam ankommen. Behalte zwei ununterbrochene Durchgänge über 6 Schläge nur, wenn C3 → F3 → C3 und G3 → C4 → G3 jede Grenze gemeinsam in der notierten Lage erreichen. Nutze entlehnte Stufe als letzte Prüfung im Außenstimmendurchgang.

# C–Fm–Cを借用する

外声優先の回でC–Fm–Cを1回読み、ピアノの3 ボイシングを6 拍保ち、低音C3 → F3 → C3と上声G3 → C4 → G3を追います。借用した度数を「モーダル・インターチェンジは1コードだけ音階音を変え、共通音とトニックへの帰還が聞こえるほど効果が明確になります」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで3 ボイシングをすべて弾き、音域を変えずC3 → F3 → C3とG3 → C4 → G3を別々に歌って借用した度数を確かめます。

外声優先の回で各記譜グループを戻し、一本の旋律としてではなく、低音ファ3→ド3と上声ド4→ソ3を重点的に聴きます。低音ファ3→ド3と上声ド4→ソ3を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。6 拍を止めずに2回録音し、C3 → F3 → C3とG3 → C4 → G3が記譜音域の各境界へ同時に着く場合だけ残します。最後に外声優先の回の借用した度数を確認します。

:::checkpoint C–Fm–Cの借用コードと変化した度数を言い、トニックへの帰還を3回弾く。

# 借用C–Fm–C

在外声部优先遍中把C–Fm–C读一遍；钢琴在6 拍内保持3 和弦排列，低音为C3 → F3 → C3，顶声部为G3 → C4 → G3。把借用音级与“调式互换只在一个和弦中改变选定音级”这个原理联系起来；方括号内各音同时开始，两条外声路线则揭示方向。以66 BPM弹完3 和弦排列，再保持音区不变，分别唱C3 → F3 → C3与G3 → C4 → G3来核对借用音级。在外声部优先遍中恢复每个写出音组，重点聆听低音fa3→do3与顶声部do4→sol3，不要把和声听成一条被摊平的旋律。

修正低音fa3→do3与顶声部do4→sol3时，只循环最后两个写出事件，直到两条外声连续两次同时到达。不中断地录下两遍6 拍；只有C3 → F3 → C3与G3 → C4 → G3都在写出音区同时到达每个边界时才保留。先把C–Fm–C在外声部优先遍中完整录一遍，再用借用音级检查第一个边界；只循环修正该处两次，随后回到原速度和音区，不要改动其他事件。最后复核外声部优先遍中的借用音级。
