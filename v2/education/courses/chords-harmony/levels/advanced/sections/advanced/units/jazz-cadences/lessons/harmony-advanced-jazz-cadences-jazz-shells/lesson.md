Leia Dm7–G7–Cmaj7 aberturas shell uma vez na passagem das vozes externas; o piano sustenta 3 aberturas por 6 tempos, com baixo D3 → G2 → C3 e topo C4 → B3 → B3. Relacione movimento das aberturas shell a este princípio: Aberturas shell expõem terças e sétimas, facilitando ouvir substituições e dominantes alteradas sem acordes densos; as notas entre colchetes começam juntas enquanto os caminhos externos revelam direção. Toque todas as 3 aberturas a 66 BPM e cante D3 → G2 → C3 e C4 → B3 → B3 separadamente para conferir movimento das aberturas shell sem mudar o registro.

Corrija baixo sol2 → dó3 e topo si3 → si3 repetindo apenas os dois eventos finais até as duas vozes externas chegarem juntas duas vezes. Guarde duas tomadas contínuas de 6 tempos apenas quando D3 → G2 → C3 e C4 → B3 → B3 alcançarem cada fronteira juntos no registro escrito. Use movimento das aberturas shell como verificação final da passagem das vozes externas.

# Dm7–G7–Cmaj7 シェル・ボイシングを弾く

外声優先の回でDm7–G7–Cmaj7 シェル・ボイシングを1回読み、ピアノの3 ボイシングを6 拍保ち、低音D3 → G2 → C3と上声C4 → B3 → B3を追います。ジャズ・シェルの動きを「シェル・ボイシングは3度と7度を露出させ、密集和音なしで代理コードやオルタード・ドミナントを聴きやすくします」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで3 ボイシングをすべて弾き、音域を変えずD3 → G2 → C3とC4 → B3 → B3を別々に歌ってジャズ・シェルの動きを確かめます。

外声優先の回で各記譜グループを戻し、一本の旋律としてではなく、低音ソ2→ド3と上声シ3→シ3を重点的に聴きます。低音ソ2→ド3と上声シ3→シ3を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。6 拍を止めずに2回録音し、D3 → G2 → C3とC4 → B3 → B3が記譜音域の各境界へ同時に着く場合だけ残します。最後に外声優先の回のジャズ・シェルの動きを確認します。

# 弹奏Dm7–G7–Cmaj7 壳式配置

在外声部优先遍中把Dm7–G7–Cmaj7 壳式配置读一遍；钢琴在6 拍内保持3 和弦排列，低音为D3 → G2 → C3，顶声部为C4 → B3 → B3。把爵士壳式移动与“壳式配置突出三音与七音，使替代和弦和变化属和弦无需密集堆叠也能听清”这个原理联系起来；方括号内各音同时开始，两条外声路线则揭示方向。以66 BPM弹完3 和弦排列，再保持音区不变，分别唱D3 → G2 → C3与C4 → B3 → B3来核对爵士壳式移动。
