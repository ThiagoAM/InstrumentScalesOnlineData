# Cmaj7 （メロディーはD）を比べる

再開しないテイクでCmaj7 （メロディーはD）を1回読み、ピアノの2 ボイシングを4 拍保ち、低音C3 → C3と上声D4 → B3を追います。テンションの優先順位を「エクステンションは7度の上へ3度堆積を続け、音域と省略音が開放的か混雑した響きかを決めます」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで2 ボイシングをすべて弾き、音域を変えずC3 → C3とD4 → B3を別々に歌ってテンションの優先順位を確かめます。

再開しないテイクで各記譜グループを戻し、一本の旋律としてではなく、低音ド3→ド3と上声レ4→シ3を重点的に聴きます。低音ド3→ド3と上声レ4→シ3を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。4 拍を止めずに2回録音し、C3 → C3とD4 → B3が記譜音域の各境界へ同時に着く場合だけ残します。最後に再開しないテイクのテンションの優先順位を確認します。
