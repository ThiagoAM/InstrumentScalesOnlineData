Relacione movimento das aberturas shell a este princípio: Aberturas shell expõem terças e sétimas, facilitando ouvir substituições e dominantes alteradas sem acordes densos; as notas entre colchetes começam juntas enquanto os caminhos externos revelam direção. Toque todas as 3 aberturas a 66 BPM e cante B2 → E2 → A2 e B3 → B3 → C4 separadamente para conferir movimento das aberturas shell sem mudar o registro.

Spiele alle 3 Lagen bei 66 BPM und singe B2 → E2 → A2 sowie B3 → B3 → C4 getrennt, um Jazz-Shell-Bewegung ohne Lagenwechsel zu prüfen.

# Bm7♭5–E7♭9–Amを解決する

無音予測の回でBm7♭5–E7♭9–Amを1回読み、ピアノの3 ボイシングを6 拍保ち、低音B2 → E2 → A2と上声B3 → B3 → C4を追います。ジャズ・シェルの動きを「シェル・ボイシングは3度と7度を露出させ、密集和音なしで代理コードやオルタード・ドミナントを聴きやすくします」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで3 ボイシングをすべて弾き、音域を変えずB2 → E2 → A2とB3 → B3 → C4を別々に歌ってジャズ・シェルの動きを確かめます。

無音予測の回で各記譜グループを戻し、一本の旋律としてではなく、低音ミ2→ラ2と上声シ3→ド4を重点的に聴きます。マイナー・カデンツではG♯→AとD→Cだけを取り出して修正し、その解決を反復してから三つの全ボイシングへ戻します。6 拍を止めずに2回録音し、B2 → E2 → A2とB3 → B3 → C4が記譜音域の各境界へ同時に着く場合だけ残します。最後に無音予測の回のジャズ・シェルの動きを確認します。
