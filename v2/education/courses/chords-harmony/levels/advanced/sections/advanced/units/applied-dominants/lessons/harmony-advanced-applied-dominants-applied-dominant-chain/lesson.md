# E7–A7–D7–G7–Cを追う

上声優先の回でE7–A7–D7–G7–Cを1回読み、ピアノの5 ボイシングを10 拍保ち、低音E3 … C3と上声D4 … G3を追います。一時的なトニックへの引力を「セカンダリー・ドミナントは到着コードの導音を一時的に導入し、主調を離れず局所的なV–Iを作ります」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで5 ボイシングをすべて弾き、音域を変えずE3 … C3とD4 … G3を別々に歌って一時的なトニックへの引力を確かめます。

上声優先の回で各記譜グループを戻し、一本の旋律としてではなく、低音ソ2→ド3と上声ファ3→ソ3を重点的に聴きます。低音ソ2→ド3と上声ファ3→ソ3を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。10 拍を止めずに2回録音し、E3 … C3とD4 … G3が記譜音域の各境界へ同時に着く場合だけ残します。最後に上声優先の回の一時的なトニックへの引力を確認します。

# 跟随E7–A7–D7–G7–C

在顶声部优先遍中把E7–A7–D7–G7–C读一遍；钢琴在10 拍内保持5 和弦排列，低音为E3 … C3，顶声部为D4 … G3。把临时主和弦引力与“副属和弦引入目标和弦的变化导音，在不离开主调的情况下形成短暂的局部V–I”这个原理联系起来；方括号内各音同时开始，两条外声路线则揭示方向。以66 BPM弹完5 和弦排列，再保持音区不变，分别唱E3 … C3与D4 … G3来核对临时主和弦引力。

在顶声部优先遍中恢复每个写出音组，重点聆听低音sol2→do3与顶声部fa3→sol3，不要把和声听成一条被摊平的旋律。修正低音sol2→do3与顶声部fa3→sol3时，只循环最后两个写出事件，直到两条外声连续两次同时到达。不中断地录下两遍10 拍；只有E3 … C3与D4 … G3都在写出音区同时到达每个边界时才保留。最后复核顶声部优先遍中的临时主和弦引力。
