# C–Am–F–Fm–Cを聴き分ける

再開しないテイクでC–Am–F–Fm–Cを1回読み、ピアノの5 ボイシングを10 拍保ち、低音C3 … C3と上声G3 … G3を追います。借用した度数を「モーダル・インターチェンジは1コードだけ音階音を変え、共通音とトニックへの帰還が聞こえるほど効果が明確になります」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで5 ボイシングをすべて弾き、音域を変えずC3 … C3とG3 … G3を別々に歌って借用した度数を確かめます。

再開しないテイクで各記譜グループを戻し、一本の旋律としてではなく、低音ファ3→ド3と上声ド4→ソ3を重点的に聴きます。低音ファ3→ド3と上声ド4→ソ3を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。10 拍を止めずに2回録音し、C3 … C3とG3 … G3が記譜音域の各境界へ同時に着く場合だけ残します。最後に再開しないテイクの借用した度数を確認します。

# 聆听C–Am–F–Fm–C

在不重启录音中把C–Am–F–Fm–C读一遍；钢琴在10 拍内保持5 和弦排列，低音为C3 … C3，顶声部为G3 … G3。把借用音级与“调式互换只在一个和弦中改变选定音级”这个原理联系起来；方括号内各音同时开始，两条外声路线则揭示方向。以66 BPM弹完5 和弦排列，再保持音区不变，分别唱C3 … C3与G3 … G3来核对借用音级。在不重启录音中恢复每个写出音组，重点聆听低音fa3→do3与顶声部do4→sol3，不要把和声听成一条被摊平的旋律。

修正低音fa3→do3与顶声部do4→sol3时，只循环最后两个写出事件，直到两条外声连续两次同时到达。不中断地录下两遍10 拍；只有C3 … C3与G3 … G3都在写出音区同时到达每个边界时才保留。先把C–Am–F–Fm–C在不重启录音中完整录一遍，再用借用音级检查第一个边界；只循环修正该处两次，随后回到原速度和音区，不要改动其他事件。最后复核不重启录音中的借用音级。
