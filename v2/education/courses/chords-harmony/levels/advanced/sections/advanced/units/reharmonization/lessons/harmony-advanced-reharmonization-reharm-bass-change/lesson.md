# C / C/E / C/Gを比べる

境界修正の回でC / C/E / C/Gを1回読み、ピアノの3 ボイシングを6 拍保ち、低音C3 → E3 → G3と上声G3 → C4 → E4を追います。メロディーを保つ代理コードを「有効なリハーモナイズはメロディー音を支え、到着先を明確にし、効果が聞こえるよう一度に一要素だけ変えます」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで3 ボイシングをすべて弾き、音域を変えずC3 → E3 → G3とG3 → C4 → E4を別々に歌ってメロディーを保つ代理コードを確かめます。

境界修正の回で各記譜グループを戻し、一本の旋律としてではなく、低音ミ3→ソ3と上声ド4→ミ4を重点的に聴きます。低音ミ3→ソ3と上声ド4→ミ4を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。6 拍を止めずに2回録音し、C3 → E3 → G3とG3 → C4 → E4が記譜音域の各境界へ同時に着く場合だけ残します。最後に境界修正の回のメロディーを保つ代理コードを確認します。
