# Acompanhe F–C → F–B → E–B

Leia F–C → F–B → E–B uma vez na passagem de contraste; o piano sustenta 3 aberturas por 6 tempos, com baixo F3 → F3 → E3 e topo C4 → B3 → B3. Relacione movimento das aberturas shell a este princípio: Aberturas shell expõem terças e sétimas, facilitando ouvir substituições e dominantes alteradas sem acordes densos; as notas entre colchetes começam juntas enquanto os caminhos externos revelam direção. Toque todas as 3 aberturas a 66 BPM e cante F3 → F3 → E3 e C4 → B3 → B3 separadamente para conferir movimento das aberturas shell sem mudar o registro.

Corrija baixo fá3 → mi3 e topo si3 → si3 repetindo apenas os dois eventos finais até as duas vozes externas chegarem juntas duas vezes. Guarde duas tomadas contínuas de 6 tempos apenas quando F3 → F3 → E3 e C4 → B3 → B3 alcançarem cada fronteira juntos no registro escrito. Use movimento das aberturas shell como verificação final da passagem de contraste.

# Sigue F–C → F–B → E–B

Lee F–C → F–B → E–B una vez en la pasada de contraste; el piano mantiene 3 disposiciones durante 6 pulsos, con bajo F3 → F3 → E3 y voz superior C4 → B3 → B3. Relaciona movimiento de disposiciones shell con este principio: Las disposiciones shell exponen terceras y séptimas y facilitan oír sustituciones y dominantes alterados sin acordes densos; las notas entre corchetes empiezan juntas mientras las líneas exteriores revelan dirección. Toca todas las 3 disposiciones a 66 BPM y canta F3 → F3 → E3 y C4 → B3 → B3 por separado para comprobar movimiento de disposiciones shell sin cambiar de registro.

Corrige bajo fa3 → mi3 y voz superior si3 → si3 repitiendo solo los dos eventos finales hasta que ambas voces exteriores lleguen juntas dos veces. Conserva dos tomas continuas de 6 pulsos solo cuando F3 → F3 → E3 y C4 → B3 → B3 alcancen juntos cada límite en el registro escrito. Usa movimiento de disposiciones shell como comprobación final de la pasada de contraste.

:::checkpoint Canta la voz más grave o indicada de F–C → F–B → E–B y toca la secuencia escrita tres veces a 66 BPM.

# Verfolge F–C → F–B → E–B

Lies F–C → F–B → E–B einmal im Kontrastdurchgang; das Klavier hält 3 Lagen über 6 Schläge, mit Bass F3 → F3 → E3 und Oberstimme C4 → B3 → B3. Verbinde Jazz-Shell-Bewegung mit diesem Prinzip: Shell-Voicings zeigen Terzen und Septimen und machen Substitutionen sowie alterierte Dominanten ohne dichte Akkorde hörbar; Klammernoten beginnen gemeinsam, während die Außenwege Richtung zeigen. Spiele alle 3 Lagen bei 66 BPM und singe F3 → F3 → E3 sowie C4 → B3 → B3 getrennt, um Jazz-Shell-Bewegung ohne Lagenwechsel zu prüfen.

Stelle im Kontrastdurchgang jede notierte Gruppe wieder her und höre gezielt auf Bass F3 → E3 und Oberstimme H3 → H3, nicht auf eine abgeflachte Einzelmelodie. Repariere Bass F3 → E3 und Oberstimme H3 → H3, indem du nur die letzten zwei Ereignisse wiederholst, bis beide Außenstimmen zweimal gemeinsam ankommen. Behalte zwei ununterbrochene Durchgänge über 6 Schläge nur, wenn F3 → F3 → E3 und C4 → B3 → B3 jede Grenze gemeinsam in der notierten Lage erreichen. Nutze Jazz-Shell-Bewegung als letzte Prüfung im Kontrastdurchgang.

# F–C → F–B → E–Bを追う

対比優先の回でF–C → F–B → E–Bを1回読み、ピアノの3 ボイシングを6 拍保ち、低音F3 → F3 → E3と上声C4 → B3 → B3を追います。ジャズ・シェルの動きを「シェル・ボイシングは3度と7度を露出させ、密集和音なしで代理コードやオルタード・ドミナントを聴きやすくします」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで3 ボイシングをすべて弾き、音域を変えずF3 → F3 → E3とC4 → B3 → B3を別々に歌ってジャズ・シェルの動きを確かめます。

対比優先の回で各記譜グループを戻し、一本の旋律としてではなく、低音ファ3→ミ3と上声シ3→シ3を重点的に聴きます。低音ファ3→ミ3と上声シ3→シ3を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。6 拍を止めずに2回録音し、F3 → F3 → E3とC4 → B3 → B3が記譜音域の各境界へ同時に着く場合だけ残します。最後に対比優先の回のジャズ・シェルの動きを確認します。

:::checkpoint F–C → F–B → E–Bの最低声部または指定された動く声部を歌い、書かれた並びを66 BPMで3回弾く。

# 跟随F–C → F–B → E–B

在对比遍中把F–C → F–B → E–B读一遍；钢琴在6 拍内保持3 和弦排列，低音为F3 → F3 → E3，顶声部为C4 → B3 → B3。把爵士壳式移动与“壳式配置突出三音与七音，使替代和弦和变化属和弦无需密集堆叠也能听清”这个原理联系起来；方括号内各音同时开始，两条外声路线则揭示方向。以66 BPM弹完3 和弦排列，再保持音区不变，分别唱F3 → F3 → E3与C4 → B3 → B3来核对爵士壳式移动。

在对比遍中恢复每个写出音组，重点聆听低音fa3→mi3与顶声部si3→si3，不要把和声听成一条被摊平的旋律。修正低音fa3→mi3与顶声部si3→si3时，只循环最后两个写出事件，直到两条外声连续两次同时到达。不中断地录下两遍6 拍；只有F3 → F3 → E3与C4 → B3 → B3都在写出音区同时到达每个边界时才保留。最后复核对比遍中的爵士壳式移动。

:::checkpoint 唱出F–C → F–B → E–B的最低声部或指定移动声部，再以66 BPM弹奏写出的序列三遍。
