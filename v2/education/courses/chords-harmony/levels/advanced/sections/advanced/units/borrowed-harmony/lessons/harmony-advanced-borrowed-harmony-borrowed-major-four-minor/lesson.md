# Empreste Am–D–Am

Leia Am–D–Am uma vez na passagem guiada pelo baixo; o piano sustenta 3 aberturas por 6 tempos, com baixo A2 → D3 → A2 e topo E3 → A3 → E3. Relacione grau emprestado a este princípio: A mistura modal altera graus escolhidos em um acorde; as notas entre colchetes começam juntas enquanto os caminhos externos revelam direção. Toque todas as 3 aberturas a 66 BPM e cante A2 → D3 → A2 e E3 → A3 → E3 separadamente para conferir grau emprestado sem mudar o registro.

Restaure cada grupo escrito durante a passagem guiada pelo baixo e ouça especificamente baixo ré3 → lá2 e topo lá3 → mi3, não uma melodia única achatada. Corrija baixo ré3 → lá2 e topo lá3 → mi3 repetindo apenas os dois eventos finais até as duas vozes externas chegarem juntas duas vezes. Guarde duas tomadas contínuas de 6 tempos apenas quando A2 → D3 → A2 e E3 → A3 → E3 alcançarem cada fronteira juntos no registro escrito. Use grau emprestado como verificação final da passagem guiada pelo baixo.

# Toma prestado Am–D–Am

Lee Am–D–Am una vez en la pasada guiada por el bajo; el piano mantiene 3 disposiciones durante 6 pulsos, con bajo A2 → D3 → A2 y voz superior E3 → A3 → E3. Relaciona grado prestado con este principio: La mezcla modal altera grados concretos durante un acorde; las notas entre corchetes empiezan juntas mientras las líneas exteriores revelan dirección. Toca todas las 3 disposiciones a 66 BPM y canta A2 → D3 → A2 y E3 → A3 → E3 por separado para comprobar grado prestado sin cambiar de registro.

Corrige bajo re3 → la2 y voz superior la3 → mi3 repitiendo solo los dos eventos finales hasta que ambas voces exteriores lleguen juntas dos veces. Conserva dos tomas continuas de 6 pulsos solo cuando A2 → D3 → A2 y E3 → A3 → E3 alcancen juntos cada límite en el registro escrito. Usa grado prestado como comprobación final de la pasada guiada por el bajo.

# Entlehne Am–D–Am

Lies Am–D–Am einmal im bassgeführter Durchgang; das Klavier hält 3 Lagen über 6 Schläge, mit Bass A2 → D3 → A2 und Oberstimme E3 → A3 → E3. Verbinde entlehnte Stufe mit diesem Prinzip: Modaler Austausch verändert ausgewählte Stufen für einen Akkord; Klammernoten beginnen gemeinsam, während die Außenwege Richtung zeigen. Spiele alle 3 Lagen bei 66 BPM und singe A2 → D3 → A2 sowie E3 → A3 → E3 getrennt, um entlehnte Stufe ohne Lagenwechsel zu prüfen.

Stelle im bassgeführter Durchgang jede notierte Gruppe wieder her und höre gezielt auf Bass D3 → A2 und Oberstimme A3 → E3, nicht auf eine abgeflachte Einzelmelodie. Repariere Bass D3 → A2 und Oberstimme A3 → E3, indem du nur die letzten zwei Ereignisse wiederholst, bis beide Außenstimmen zweimal gemeinsam ankommen. Behalte zwei ununterbrochene Durchgänge über 6 Schläge nur, wenn A2 → D3 → A2 und E3 → A3 → E3 jede Grenze gemeinsam in der notierten Lage erreichen. Nutze entlehnte Stufe als letzte Prüfung im bassgeführter Durchgang.

# Am–D–Amを借用する

低音主導の回でAm–D–Amを1回読み、ピアノの3 ボイシングを6 拍保ち、低音A2 → D3 → A2と上声E3 → A3 → E3を追います。借用した度数を「モーダル・インターチェンジは1コードだけ音階音を変え、共通音とトニックへの帰還が聞こえるほど効果が明確になります」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで3 ボイシングをすべて弾き、音域を変えずA2 → D3 → A2とE3 → A3 → E3を別々に歌って借用した度数を確かめます。

低音主導の回で各記譜グループを戻し、一本の旋律としてではなく、低音レ3→ラ2と上声ラ3→ミ3を重点的に聴きます。低音レ3→ラ2と上声ラ3→ミ3を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。6 拍を止めずに2回録音し、A2 → D3 → A2とE3 → A3 → E3が記譜音域の各境界へ同時に着く場合だけ残します。最後に低音主導の回の借用した度数を確認します。

:::checkpoint Am–D–Amの借用コードと変化した度数を言い、トニックへの帰還を3回弾く。

# 借用Am–D–Am

在低音主导遍中把Am–D–Am读一遍；钢琴在6 拍内保持3 和弦排列，低音为A2 → D3 → A2，顶声部为E3 → A3 → E3。把借用音级与“调式互换只在一个和弦中改变选定音级”这个原理联系起来；方括号内各音同时开始，两条外声路线则揭示方向。以66 BPM弹完3 和弦排列，再保持音区不变，分别唱A2 → D3 → A2与E3 → A3 → E3来核对借用音级。在低音主导遍中恢复每个写出音组，重点聆听低音re3→la2与顶声部la3→mi3，不要把和声听成一条被摊平的旋律。

修正低音re3→la2与顶声部la3→mi3时，只循环最后两个写出事件，直到两条外声连续两次同时到达。不中断地录下两遍6 拍；只有A2 → D3 → A2与E3 → A3 → E3都在写出音区同时到达每个边界时才保留。先把Am–D–Am在低音主导遍中完整录一遍，再用借用音级检查第一个边界；只循环修正该处两次，随后回到原速度和音区，不要改动其他事件。最后复核低音主导遍中的借用音级。
