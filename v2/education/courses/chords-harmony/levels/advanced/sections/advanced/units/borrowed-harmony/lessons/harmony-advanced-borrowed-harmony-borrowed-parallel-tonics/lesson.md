# Hear parallel C / Cm

Read parallel C / Cm in the root-first pass; hold root, register, volume, and touch while changed interval changes. Separate A from B through changed interval, not loudness, then match borrowed degree against the key. Mark borrowed scale degree at 68 BPM; alternate A degrees 1–3–5 with B semitones 0–3–7, leaving one silent beat. Sing A 1 against B 0 in the root-first pass before either label appears, then track modal color inside tonality.

Make one diagnostic recording of parallel C / Cm in the root-first pass; on playback, mark the first moment where borrowed scale degree succeeds or fails, rehearse that moment twice, and return to the complete example. Correct borrowed scale degree by isolating A 1 against B 0; restore matched volume and one silent beat. a clear return from borrowing sets the test; keep two blind labels with a spoken reason naming changed interval.

# Ouça paralelo C / Cm

Ouça paralelo C / Cm uma vez na passagem pela fundamental, mantendo fundamental, registro, volume e ataque enquanto A (graus 1 3 5) contra B (semitons 0 3 7; graus 1 2 3) muda. Relacione grau emprestado a este princípio: A mistura modal altera graus escolhidos em um acorde; a diferença controlada explica por que A e B não têm a mesma função ou cor. Alterne A, um–três–cinco, com B, uníssono–terça menor–quinta justa, quatro vezes a 68 BPM; use grau emprestado para deixar um tempo de silêncio entre os lados.

Corrija uma resposta incerta isolando um–três–cinco de uníssono–terça menor–quinta justa e restaure volume igual e silêncio antes de comparar outra vez. Guarde as duas tentativas cegas finais apenas quando os rótulos estiverem certos e a justificativa identificar A (graus 1 3 5) contra B (semitons 0 3 7; graus 1 2 3), não volume ou registro. Use grau emprestado como verificação final da passagem pela fundamental.

:::checkpoint Ouça paralelo C / Cm uma vez sem olhar, diga a qualidade ou o destino e reproduza novamente para conferir.

# Escucha paralelo C / Cm

Escucha paralelo C / Cm una vez en la pasada desde la fundamental, manteniendo fundamental, registro, volumen y ataque mientras cambia A (grados 1 3 5) frente a B (semitonos 0 3 7; grados 1 2 3). Relaciona grado prestado con este principio: La mezcla modal altera grados concretos durante un acorde; la diferencia controlada explica por qué A y B no tienen la misma función o color. Alterna A, uno–tres–cinco, con B, unísono–tercera menor–quinta justa, cuatro veces a 68 BPM; usa grado prestado para dejar un pulso de silencio entre lados.

Corrige una respuesta incierta aislando uno–tres–cinco de unísono–tercera menor–quinta justa y recupera volumen igual y silencio antes de comparar de nuevo. Conserva los dos intentos ciegos finales solo cuando las etiquetas sean correctas y la razón identifique A (grados 1 3 5) frente a B (semitonos 0 3 7; grados 1 2 3), no volumen ni registro. Usa grado prestado como comprobación final de la pasada desde la fundamental.

# Höre parallel C / Cm

Höre parallel C / Cm einmal im grundtonbezogener Durchgang; halte Grundton, Lage, Lautstärke und Anschlag fest, während A (Stufen 1 3 5) gegenüber B (Halbtöne 0 3 7; Stufen 1 2 3) wechselt. Verbinde entlehnte Stufe mit diesem Prinzip: Modaler Austausch verändert ausgewählte Stufen für einen Akkord; der kontrollierte Unterschied erklärt die verschiedene Funktion oder Farbe von A und B. Wechsle A, eins–drei–fünf, und B, Prime–kleine Terz–reine Quinte, viermal bei 68 BPM; lass mit entlehnte Stufe einen stillen Schlag zwischen den Seiten.

Benenne A (Stufen 1 3 5) gegenüber B (Halbtöne 0 3 7; Stufen 1 2 3) im grundtonbezogener Durchgang und singe den ersten veränderten Ton, bevor das A- oder B-Etikett erscheint. Repariere eine unsichere Antwort, indem du eins–drei–fünf von Prime–kleine Terz–reine Quinte isolierst und vor dem neuen Vergleich Lautstärke und Pause gleichsetzt. Behalte die letzten zwei Blindversuche nur mit richtigen Etiketten und einer Begründung über A (Stufen 1 3 5) gegenüber B (Halbtöne 0 3 7; Stufen 1 2 3) statt Lautstärke oder Lage. Nutze entlehnte Stufe als letzte Prüfung im grundtonbezogener Durchgang.

:::checkpoint Höre parallel C / Cm einmal ohne hinzusehen, nenne Qualität oder Ziel und prüfe die Antwort beim nächsten Durchgang.

# 平行調 C / Cmを聴き分ける

ルート優先の回で平行調 C / Cmを1回聴き、共通のルート、音域、音量、タッチを固定してA（度数 1 3 5）とB（半音 0 3 7; 度数 1 2 3）の差だけを変えます。借用した度数を「モーダル・インターチェンジは1コードだけ音階音を変え。共通音とトニックへの帰還が聞こえるほど効果が明確になります」という原理と結び、制御した差によってAとBの機能または色が違う理由を説明します。Aの一–三–五とBのユニゾン–短3度–完全5度を68 BPMで4回交互に聴き、借用した度数を基準に両側の間へ1拍の無音を置きます。

ルート優先の回でA（度数 1 3 5）とB（半音 0 3 7; 度数 1 2 3）の差を言葉にし、AまたはBのラベルを見る前に最初の変化音を歌います。答えが曖昧なら一–三–五とユニゾン–短3度–完全5度を分け、同じ音量と1拍の無音を戻してから再び比較します。最後の2回はブラインドで行い、両方のラベルが正しく、理由が音量や音域ではなくA（度数 1 3 5）とB（半音 0 3 7; 度数 1 2 3）の差を示した場合だけ残します。最後にルート優先の回の借用した度数を確認します。

:::checkpoint 平行調 C / Cmを画面を見ずに一度聴き、クオリティまたは到着先を答えてから再生で確認する。

# 聆听同主音 C / Cm

在根音优先遍中听同主音 C / Cm一遍；固定共同根音、音区、音量与触键，只让A（音级 1 3 5）与B（半音 0 3 7; 音级 1 2 3）的差异发生变化。把借用音级与“调式互换只在一个和弦中改变选定音级”这个原理联系起来；受控差异必须说明A与B为何具有不同功能或色彩。以68 BPM把A的一–三–五与B的同度–小三度–纯五度交替四遍；依据借用音级在两边之间留一拍完整安静。

在根音优先遍中说出A（音级 1 3 5）与B（半音 0 3 7; 音级 1 2 3）的差异，并在揭示A或B标签之前唱出第一个变化音。若答案不确定，先把一–三–五与同度–小三度–纯五度分离，再恢复相同音量与一拍安静，然后重新比较。最后两次采用盲听；只有两个标签都正确，而且口头理由指出A（音级 1 3 5）与B（半音 0 3 7; 音级 1 2 3）的差异而不是音量或音区时才保留。最后复核根音优先遍中的借用音级。
