# C–Caug–Am/Cをつなぐ

再開しないテイクでC–Caug–Am/Cを1回読み、ピアノの3 ボイシングを6 拍保ち、低音C3 → C3 → C3と上声G3 → G♯3 → A3を追います。変化和音の対称性を「ディミニッシュは音程を縮め、オーギュメントは5度を広げます」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで3 ボイシングをすべて弾き、音域を変えずC3 → C3 → C3とG3 → G♯3 → A3を別々に歌って変化和音の対称性を確かめます。

再開しないテイクで各記譜グループを戻し、一本の旋律としてではなく、低音ド3→ド3と上声ソ・シャープ3→ラ3を重点的に聴きます。低音ド3→ド3と上声ソ・シャープ3→ラ3を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。6 拍を止めずに2回録音し、C3 → C3 → C3とG3 → G♯3 → A3が記譜音域の各境界へ同時に着く場合だけ残します。最後に再開しないテイクの変化和音の対称性を確認します。

修正低音do3→do3与顶声部sol升3→la3时，只循环最后两个写出事件，直到两条外声连续两次同时到达。不中断地录下两遍6 拍；只有C3 → C3 → C3与G3 → G♯3 → A3都在写出音区同时到达每个边界时才保留。先把C–Caug–Am/C在不重启录音中完整录一遍，再用变化和弦对称性检查第一个边界；只循环修正该处两次，随后回到原速度和音区，不要改动其他事件。最后复核不重启录音中的变化和弦对称性。
