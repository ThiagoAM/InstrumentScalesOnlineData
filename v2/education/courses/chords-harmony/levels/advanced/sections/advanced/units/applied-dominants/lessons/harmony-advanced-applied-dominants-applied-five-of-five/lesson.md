# D7 → G → Cを解決する

ルート優先の回でD7 → G → Cを1回読み、ピアノの3 ボイシングを6 拍保ち、低音D3 → G2 → C3と上声C4 → G3 → G3を追います。一時的なトニックへの引力を「セカンダリー・ドミナントは到着コードの導音を一時的に導入し、主調を離れず局所的なV–Iを作ります」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで3 ボイシングをすべて弾き、音域を変えずD3 → G2 → C3とC4 → G3 → G3を別々に歌って一時的なトニックへの引力を確かめます。

ルート優先の回で各記譜グループを戻し、一本の旋律としてではなく、低音ソ2→ド3と上声ソ3→ソ3を重点的に聴きます。低音ソ2→ド3と上声ソ3→ソ3を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。6 拍を止めずに2回録音し、D3 → G2 → C3とC4 → G3 → G3が記譜音域の各境界へ同時に着く場合だけ残します。最後にルート優先の回の一時的なトニックへの引力を確認します。
