# Am–E–Aを解決する

上声優先の回でAm–E–Aを1回読み、ピアノの3 ボイシングを6 拍保ち、低音A2 → E3 → A2と上声E3 → B3 → E3を追います。借用した度数を「モーダル・インターチェンジは1コードだけ音階音を変え、共通音とトニックへの帰還が聞こえるほど効果が明確になります」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで3 ボイシングをすべて弾き、音域を変えずA2 → E3 → A2とE3 → B3 → E3を別々に歌って借用した度数を確かめます。

上声優先の回で各記譜グループを戻し、一本の旋律としてではなく、低音ミ3→ラ2と上声シ3→ミ3を重点的に聴きます。低音ミ3→ラ2と上声シ3→ミ3を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。6 拍を止めずに2回録音し、A2 → E3 → A2とE3 → B3 → E3が記譜音域の各境界へ同時に着く場合だけ残します。最後に上声優先の回の借用した度数を確認します。

# 解决Am–E–A

在顶声部优先遍中把Am–E–A读一遍；钢琴在6 拍内保持3 和弦排列，低音为A2 → E3 → A2，顶声部为E3 → B3 → E3。把借用音级与“调式互换只在一个和弦中改变选定音级”这个原理联系起来；方括号内各音同时开始，两条外声路线则揭示方向。以66 BPM弹完3 和弦排列，再保持音区不变，分别唱A2 → E3 → A2与E3 → B3 → E3来核对借用音级。在顶声部优先遍中恢复每个写出音组，重点聆听低音mi3→la2与顶声部si3→mi3，不要把和声听成一条被摊平的旋律。

修正低音mi3→la2与顶声部si3→mi3时，只循环最后两个写出事件，直到两条外声连续两次同时到达。不中断地录下两遍6 拍；只有A2 → E3 → A2与E3 → B3 → E3都在写出音区同时到达每个边界时才保留。先把Am–E–A在顶声部优先遍中完整录一遍，再用借用音级检查第一个边界；只循环修正该处两次，随后回到原速度和音区，不要改动其他事件。最后复核顶声部优先遍中的借用音级。
