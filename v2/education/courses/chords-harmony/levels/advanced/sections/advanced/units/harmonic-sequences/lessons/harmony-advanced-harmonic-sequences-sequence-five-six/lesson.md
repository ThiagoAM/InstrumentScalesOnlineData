# 5–6 C–Dm–Em上を追う

対比優先の回で5–6 C–Dm–Em上を1回読み、ピアノの3 ボイシングを6 拍保ち、低音C3 → D3 → E3と上声E4 → F4 → G4を追います。シークエンス・セルを「シークエンスは開始位置を移しても音程の動きを保ち、明確な声部進行が機械的な反復を防ぎます」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで3 ボイシングをすべて弾き、音域を変えずC3 → D3 → E3とE4 → F4 → G4を別々に歌ってシークエンス・セルを確かめます。

対比優先の回で各記譜グループを戻し、一本の旋律としてではなく、低音レ3→ミ3と上声ファ4→ソ4を重点的に聴きます。低音レ3→ミ3と上声ファ4→ソ4を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。6 拍を止めずに2回録音し、C3 → D3 → E3とE4 → F4 → G4が記譜音域の各境界へ同時に着く場合だけ残します。最後に対比優先の回のシークエンス・セルを確認します。
