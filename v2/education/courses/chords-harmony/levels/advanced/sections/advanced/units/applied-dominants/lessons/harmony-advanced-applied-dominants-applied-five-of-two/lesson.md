# A7 → Dmを解決する

外声優先の回でA7 → Dmを1回読み、ピアノの2 ボイシングを4 拍保ち、低音A2 → D3と上声G3 → A3を追います。一時的なトニックへの引力を「セカンダリー・ドミナントは到着コードの導音を一時的に導入し、主調を離れず局所的なV–Iを作ります」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで2 ボイシングをすべて弾き、音域を変えずA2 → D3とG3 → A3を別々に歌って一時的なトニックへの引力を確かめます。

外声優先の回で各記譜グループを戻し、一本の旋律としてではなく、低音ラ2→レ3と上声ソ3→ラ3を重点的に聴きます。低音ラ2→レ3と上声ソ3→ラ3を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。4 拍を止めずに2回録音し、A2 → D3とG3 → A3が記譜音域の各境界へ同時に着く場合だけ残します。最後に外声優先の回の一時的なトニックへの引力を確認します。
