# Compare C → C/E → C/G

Predict C → C/E → C/G in the silent-prediction pass; 3 written voicings span 6 beats through bass do3 → sol3, top sol3 → mi4. Align bass do3 → sol3 with top sol3 → mi4; attack each bracket together, then imagine identity above a changed bass. Test inversion bass at 66 BPM; sing do3 → sol3 below sol3 → mi4, then play 3 written voicings. Keep bass do3 → sol3, top sol3 → mi4 as separate outer lines through the silent-prediction pass, then compare an audible inversion bass.

Predict the hardest boundary in C → C/E → C/G before the silent-prediction pass; check that prediction against playback, use inversion bass to name what actually changed, and rehearse only the smaller span before another full pass. Revise inversion bass: repeat the closing boundary at bass do3 → sol3, top sol3 → mi4; coordinate both arrivals twice. stable weight after revoicing sets the test; retain a pair of 6-beat passes aligning bass do3 → sol3, top sol3 → mi4 at every change without changing register.

# Compare C → C/E → C/G

Leia C → C/E → C/G uma vez na passagem de previsão silenciosa; o piano sustenta 3 aberturas por 6 tempos, com baixo C3 → E3 → G3 e topo G3 → C4 → E4. Relacione baixo da inversão a este princípio: Uma inversão preserva as notas do acorde, mas põe terça ou quinta no baixo, mudando o peso sem mudar a identidade; as notas entre colchetes começam juntas enquanto os caminhos externos revelam direção. Toque todas as 3 aberturas a 66 BPM e cante C3 → E3 → G3 e G3 → C4 → E4 separadamente para conferir baixo da inversão sem mudar o registro.

Corrija baixo mi3 → sol3 e topo dó4 → mi4 repetindo apenas os dois eventos finais até as duas vozes externas chegarem juntas duas vezes. Guarde duas tomadas contínuas de 6 tempos apenas quando C3 → E3 → G3 e G3 → C4 → E4 alcançarem cada fronteira juntos no registro escrito. Use baixo da inversão como verificação final da passagem de previsão silenciosa.

:::checkpoint Compare as duas versões de C → C/E → C/G quatro vezes a 66 BPM e identifique abertura e registro duas vezes sem olhar.

# Compara C → C/E → C/G

Lee C → C/E → C/G una vez en la pasada de predicción silenciosa; el piano mantiene 3 disposiciones durante 6 pulsos, con bajo C3 → E3 → G3 y voz superior G3 → C4 → E4. Toca todas las 3 disposiciones a 66 BPM y canta C3 → E3 → G3 y G3 → C4 → E4 por separado para comprobar bajo de la inversión sin cambiar de registro.

Corrige bajo mi3 → sol3 y voz superior do4 → mi4 repitiendo solo los dos eventos finales hasta que ambas voces exteriores lleguen juntas dos veces. Conserva dos tomas continuas de 6 pulsos solo cuando C3 → E3 → G3 y G3 → C4 → E4 alcancen juntos cada límite en el registro escrito. Usa bajo de la inversión como comprobación final de la pasada de predicción silenciosa.

# Vergleiche C → C/E → C/G

Lies C → C/E → C/G einmal im stiller Vorhersagedurchgang; das Klavier hält 3 Lagen über 6 Schläge, mit Bass C3 → E3 → G3 und Oberstimme G3 → C4 → E4. Verbinde Umkehrungsbass mit diesem Prinzip: Eine Umkehrung behält die Akkordtöne, setzt aber Terz oder Quinte in den Bass und verändert so das Gewicht, nicht die Identität; Klammernoten beginnen gemeinsam, während die Außenwege Richtung zeigen. Spiele alle 3 Lagen bei 66 BPM und singe C3 → E3 → G3 sowie G3 → C4 → E4 getrennt, um Umkehrungsbass ohne Lagenwechsel zu prüfen.

Stelle im stiller Vorhersagedurchgang jede notierte Gruppe wieder her und höre gezielt auf Bass E3 → G3 und Oberstimme C4 → E4, nicht auf eine abgeflachte Einzelmelodie. Repariere Bass E3 → G3 und Oberstimme C4 → E4, indem du nur die letzten zwei Ereignisse wiederholst, bis beide Außenstimmen zweimal gemeinsam ankommen. Behalte zwei ununterbrochene Durchgänge über 6 Schläge nur, wenn C3 → E3 → G3 und G3 → C4 → E4 jede Grenze gemeinsam in der notierten Lage erreichen. Nutze Umkehrungsbass als letzte Prüfung im stiller Vorhersagedurchgang.

# C → C/E → C/Gを比べる

無音予測の回でC → C/E → C/Gを1回読み、ピアノの3 ボイシングを6 拍保ち、低音C3 → E3 → G3と上声G3 → C4 → E4を追います。転回形の低音を「転回形は構成音を保ったまま3度または5度を低音に置き、コードの同一性を変えず重心を変えます」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで3 ボイシングをすべて弾き、音域を変えずC3 → E3 → G3とG3 → C4 → E4を別々に歌って転回形の低音を確かめます。

無音予測の回で各記譜グループを戻し、一本の旋律としてではなく、低音ミ3→ソ3と上声ド4→ミ4を重点的に聴きます。低音ミ3→ソ3と上声ド4→ミ4を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。6 拍を止めずに2回録音し、C3 → E3 → G3とG3 → C4 → E4が記譜音域の各境界へ同時に着く場合だけ残します。最後に無音予測の回の転回形の低音を確認します。

:::checkpoint C → C/E → C/Gの2種類を66 BPMで4回比べ、画面を見ずにボイシングと音域を2回答える。

# 比较C → C/E → C/G

在无声预测遍中把C → C/E → C/G读一遍；钢琴在6 拍内保持3 和弦排列，低音为C3 → E3 → G3，顶声部为G3 → C4 → E4。把转位低音与“转位保留和弦音，却把三音或五音放在低音，使重心变化而和弦身份不变”这个原理联系起来；方括号内各音同时开始，两条外声路线则揭示方向。以66 BPM弹完3 和弦排列，再保持音区不变，分别唱C3 → E3 → G3与G3 → C4 → E4来核对转位低音。在无声预测遍中恢复每个写出音组，重点聆听低音mi3→sol3与顶声部do4→mi4，不要把和声听成一条被摊平的旋律。

修正低音mi3→sol3与顶声部do4→mi4时，只循环最后两个写出事件，直到两条外声连续两次同时到达。不中断地录下两遍6 拍；只有C3 → E3 → G3与G3 → C4 → E4都在写出音区同时到达每个边界时才保留。先把C → C/E → C/G在无声预测遍中完整录一遍，再用转位低音检查第一个边界；只循环修正该处两次，随后回到原速度和音区，不要改动其他事件。最后复核无声预测遍中的转位低音。

:::checkpoint 以66 BPM比较C → C/E → C/G的两个版本四遍，并在不看屏幕时两次说出和弦排列与音区。
