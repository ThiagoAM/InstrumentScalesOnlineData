# Dm → Gを弾く

対比優先の回でDm → Gを1回読み、ドをトニックにしたスーパートニック (ii)–ドミナント (V)の2 回の変化を8 拍に収めます。切れ目のない変化を「滑らかな変更は安定したカウントと小さな動きから始まり、両コードがそろって鳴ってから速度を上げます」という原理と結び、再生前に各機能が次の低音ルートへ向くことを予測します。ii Vの各コードを4 拍数え、切れ目のない変化を基準に2 回の変化を均等にして、ii → Vを急ぎません。

対比優先の回で低音ルートを歌い、ii → Vを一つの到着として聴いて、最後のコードの機能を言います。対比優先の回で到着の遅れを直すには、ii → Vを各コード4 拍で2回反復し、止めずに前の機能を戻します。対比優先の回では、72 BPMで2回弾き、各変化が均等で、ii → Vの働きを正答した場合だけ残します。最後に対比優先の回の切れ目のない変化を確認します。

:::checkpoint Dm → Gを72 BPMで3回弾き、最後の前に追うルート、低音、機能のどれかを言う。
