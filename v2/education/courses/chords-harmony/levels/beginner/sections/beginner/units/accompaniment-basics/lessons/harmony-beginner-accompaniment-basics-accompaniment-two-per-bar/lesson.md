# I–V–vi–IV, 1小節に2コードを編曲する

低音主導の回でI–V–vi–IV, 1小節に2コードを1回読み、ドをトニックにしたトニック (I)–ドミナント (V)–サブメディアント (vi)–サブドミナント (IV)の4 回の変化を8 拍に収めます。伴奏テクスチャを「伴奏は楽句を支えます」という原理と結び、再生前に各機能が次の低音ルートへ向くことを予測します。I V vi IVの各コードを2 拍数え、伴奏テクスチャを基準に4 回の変化を均等にして、vi → IVを急ぎません。

低音主導の回で低音ルートを歌い、vi → IVを一つの到着として聴いて、最後のコードの機能を言います。低音主導の回で到着の遅れを直すには、vi → IVを各コード2 拍で2回反復し、止めずに前の機能を戻します。低音主導の回では、72 BPMで2回弾き、各変化が均等で、vi → IVの働きを正答した場合だけ残します。最後に低音主導の回の伴奏テクスチャを確認します。

# 编配I–V–vi–IV, 每小节两个

在低音主导遍中把I–V–vi–IV, 每小节两个读一遍；以do为主音的主功能 (I)–属功能 (V)–下中音功能 (vi)–下属功能 (IV)把4 次变化放进8 拍。把伴奏织体与“伴奏服务于乐句：柱式和弦标记节点，琶音制造流动，休止为旋律留出空间”这个原理联系起来；播放前，每个功能都应指向下一个低音根音。I V vi IV中的每个和弦都数2 拍；依据伴奏织体让4 次变化保持等长，不要在vi → IV处加速。

在低音主导遍中唱出低音根音，再把vi → IV听成一次到达，并说出最后一个和弦的功能。在低音主导遍中修正迟缓到达时，用每个和弦2 拍的时值循环vi → IV两次，再不停顿地恢复前面的功能。在低音主导遍中以72 BPM完成两遍；只有每次变化等长并能说明vi → IV的作用时才保留。最后复核低音主导遍中的伴奏织体。
