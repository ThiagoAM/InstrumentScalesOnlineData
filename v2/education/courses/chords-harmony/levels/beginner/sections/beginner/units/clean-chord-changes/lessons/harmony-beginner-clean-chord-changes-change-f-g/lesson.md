# F → Gを弾く

上声優先の回でF → Gを1回読み、ドをトニックにしたサブドミナント (IV)–ドミナント (V)の2 回の変化を4 拍に収めます。切れ目のない変化を「滑らかな変更は安定したカウントと小さな動きから始まり、両コードがそろって鳴ってから速度を上げます」という原理と結び、再生前に各機能が次の低音ルートへ向くことを予測します。IV Vの各コードを2 拍数え、切れ目のない変化を基準に2 回の変化を均等にして、IV → Vを急ぎません。

上声優先の回で低音ルートを歌い、IV → Vを一つの到着として聴いて、最後のコードの機能を言います。上声優先の回で到着の遅れを直すには、IV → Vを各コード2 拍で2回反復し、止めずに前の機能を戻します。上声優先の回では、72 BPMで2回弾き、各変化が均等で、IV → Vの働きを正答した場合だけ残します。最後に上声優先の回の切れ目のない変化を確認します。

:::checkpoint F → Gを72 BPMで3回弾き、最後の前に追うルート、低音、機能のどれかを言う。
