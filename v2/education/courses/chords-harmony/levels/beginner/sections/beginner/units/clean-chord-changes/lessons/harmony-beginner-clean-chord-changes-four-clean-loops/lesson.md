# I–vi–IV–Vを弾く

応用優先の回でI–vi–IV–Vを1回読み、ドをトニックにしたトニック (I)–サブメディアント (vi)–サブドミナント (IV)–ドミナント (V)の4 回の変化を8 拍に収めます。切れ目のない変化を「滑らかな変更は安定したカウントと小さな動きから始まり、両コードがそろって鳴ってから速度を上げます」という原理と結び、再生前に各機能が次の低音ルートへ向くことを予測します。I vi IV Vの各コードを2 拍数え、切れ目のない変化を基準に4 回の変化を均等にして、IV → Vを急ぎません。

応用優先の回で低音ルートを歌い、IV → Vを一つの到着として聴いて、最後のコードの機能を言います。応用優先の回で到着の遅れを直すには、IV → Vを各コード2 拍で2回反復し、止めずに前の機能を戻します。応用優先の回では、76 BPMで2回弾き、各変化が均等で、IV → Vの働きを正答した場合だけ残します。最後に応用優先の回の切れ目のない変化を確認します。
