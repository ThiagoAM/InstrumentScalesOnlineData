# G → D → Em → Cを弾く

再開しないテイクでG → D → Em → Cを1回読み、ソをトニックにしたトニック (I)–ドミナント (V)–サブメディアント (vi)–サブドミナント (IV)の4 回の変化を8 拍に収めます。切れ目のない変化を「滑らかな変更は安定したカウントと小さな動きから始まり、両コードがそろって鳴ってから速度を上げます」という原理と結び、再生前に各機能が次の低音ルートへ向くことを予測します。I V vi IVの各コードを2 拍数え、切れ目のない変化を基準に4 回の変化を均等にして、vi → IVを急ぎません。

再開しないテイクで低音ルートを歌い、vi → IVを一つの到着として聴いて、最後のコードの機能を言います。再開しないテイクで到着の遅れを直すには、vi → IVを各コード2 拍で2回反復し、止めずに前の機能を戻します。再開しないテイクでは、72 BPMで2回弾き、各変化が均等で、vi → IVの働きを正答した場合だけ残します。最後に再開しないテイクの切れ目のない変化を確認します。
