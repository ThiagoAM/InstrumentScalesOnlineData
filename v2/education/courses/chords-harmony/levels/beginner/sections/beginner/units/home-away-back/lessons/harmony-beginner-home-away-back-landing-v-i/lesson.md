# V → Iを解決する

低音主導の回でV → Iを1回読み、ドをトニックにしたドミナント (V)–トニック (I)の2 回の変化を6 拍に収めます。トニックへの引力を「Iが調の基準、IVが空間を開き、Vが方向を作り、viが完全な到着を先延ばしにします」という原理と結び、再生前に各機能が次の低音ルートへ向くことを予測します。V Iの各コードを3 拍数え、トニックへの引力を基準に2 回の変化を均等にして、V → Iを急ぎません。

低音主導の回で低音ルートを歌い、V → Iを一つの到着として聴いて、最後のコードの機能を言います。低音主導の回で到着の遅れを直すには、V → Iを各コード3 拍で2回反復し、止めずに前の機能を戻します。低音主導の回では、72 BPMで2回弾き、各変化が均等で、V → Iの働きを正答した場合だけ残します。最後に低音主導の回のトニックへの引力を確認します。
