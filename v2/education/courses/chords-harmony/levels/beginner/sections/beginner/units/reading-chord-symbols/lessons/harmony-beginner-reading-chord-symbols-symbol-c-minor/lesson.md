# Cmを読む

外声優先の回でCmを確かめ、ルートで短3度を支え、68 BPMのアルペジオでその色を明瞭に保ちます。コード記号の読みを「文字だけならメジャーで、m、7、maj7、dim、sus、add9、スラッシュはそれぞれ具体的な指示を加えます」という原理と結び、他の構成音を加える前に決め手の音程を聞き取ります。アルペジオで3 回のアタックを行い、音域と強弱を固定して、短3度をコード記号の読みに照らして判断します。

外声優先の回では保持したルートの上で短3度を歌い、同じ綴りのままコードを1音ずつ組み直します。短3度が隠れたら、覆う音だけを弱め、ボイシングを広げたりルートを強く叩いたりしません。アルペジオを3回続け、短3度が明瞭に始まり、全構成音がそろって入り、離鍵もきれいな場合だけ残します。最後に外声優先の回のコード記号の読みを確認します。
