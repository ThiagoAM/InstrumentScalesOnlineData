# Ouça C → C/E → C/G → C

Leia C → C/E → C/G → C uma vez na passagem de transferência; o piano sustenta 4 aberturas por 8 tempos, com baixo C3 … C3 e topo G3 … G3. Relacione baixo da inversão a este princípio: Uma inversão preserva as notas do acorde, mas põe terça ou quinta no baixo, mudando o peso sem mudar a identidade; as notas entre colchetes começam juntas enquanto os caminhos externos revelam direção. Toque todas as 4 aberturas a 66 BPM e cante C3 … C3 e G3 … G3 separadamente para conferir baixo da inversão sem mudar o registro.

Corrija baixo sol3 → dó3 e topo mi4 → sol3 repetindo apenas os dois eventos finais até as duas vozes externas chegarem juntas duas vezes. Guarde duas tomadas contínuas de 8 tempos apenas quando C3 … C3 e G3 … G3 alcançarem cada fronteira juntos no registro escrito. Use baixo da inversão como verificação final da passagem de transferência.

# Escucha C → C/E → C/G → C

Lee C → C/E → C/G → C una vez en la pasada de transferencia; el piano mantiene 4 disposiciones durante 8 pulsos, con bajo C3 … C3 y voz superior G3 … G3. Relaciona bajo de la inversión con este principio: Una inversión conserva las notas del acorde, pero coloca tercera o quinta en el bajo y cambia el peso sin cambiar la identidad; las notas entre corchetes empiezan juntas mientras las líneas exteriores revelan dirección. Toca todas las 4 disposiciones a 66 BPM y canta C3 … C3 y G3 … G3 por separado para comprobar bajo de la inversión sin cambiar de registro.

Corrige bajo sol3 → do3 y voz superior mi4 → sol3 repitiendo solo los dos eventos finales hasta que ambas voces exteriores lleguen juntas dos veces. Conserva dos tomas continuas de 8 pulsos solo cuando C3 … C3 y G3 … G3 alcancen juntos cada límite en el registro escrito. Usa bajo de la inversión como comprobación final de la pasada de transferencia.

# Höre C → C/E → C/G → C

Lies C → C/E → C/G → C einmal im Übertragungsdurchgang; das Klavier hält 4 Lagen über 8 Schläge, mit Bass C3 … C3 und Oberstimme G3 … G3. Verbinde Umkehrungsbass mit diesem Prinzip: Eine Umkehrung behält die Akkordtöne, setzt aber Terz oder Quinte in den Bass und verändert so das Gewicht, nicht die Identität; Klammernoten beginnen gemeinsam, während die Außenwege Richtung zeigen. Spiele alle 4 Lagen bei 66 BPM und singe C3 … C3 sowie G3 … G3 getrennt, um Umkehrungsbass ohne Lagenwechsel zu prüfen.

Stelle im Übertragungsdurchgang jede notierte Gruppe wieder her und höre gezielt auf Bass G3 → C3 und Oberstimme E4 → G3, nicht auf eine abgeflachte Einzelmelodie. Repariere Bass G3 → C3 und Oberstimme E4 → G3, indem du nur die letzten zwei Ereignisse wiederholst, bis beide Außenstimmen zweimal gemeinsam ankommen. Behalte zwei ununterbrochene Durchgänge über 8 Schläge nur, wenn C3 … C3 und G3 … G3 jede Grenze gemeinsam in der notierten Lage erreichen. Nutze Umkehrungsbass als letzte Prüfung im Übertragungsdurchgang.

# C → C/E → C/G → Cを聴き分ける

応用優先の回でC → C/E → C/G → Cを1回読み、ピアノの4 ボイシングを8 拍保ち、低音C3 … C3と上声G3 … G3を追います。転回形の低音を「転回形は構成音を保ったまま3度または5度を低音に置き、コードの同一性を変えず重心を変えます」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで4 ボイシングをすべて弾き、音域を変えずC3 … C3とG3 … G3を別々に歌って転回形の低音を確かめます。

応用優先の回で各記譜グループを戻し、一本の旋律としてではなく、低音ソ3→ド3と上声ミ4→ソ3を重点的に聴きます。低音ソ3→ド3と上声ミ4→ソ3を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。8 拍を止めずに2回録音し、C3 … C3とG3 … G3が記譜音域の各境界へ同時に着く場合だけ残します。最後に応用優先の回の転回形の低音を確認します。

# 聆听C → C/E → C/G → C

在转用遍中把C → C/E → C/G → C读一遍；钢琴在8 拍内保持4 和弦排列，低音为C3 … C3，顶声部为G3 … G3。把转位低音与“转位保留和弦音，却把三音或五音放在低音，使重心变化而和弦身份不变”这个原理联系起来；方括号内各音同时开始，两条外声路线则揭示方向。以66 BPM弹完4 和弦排列，再保持音区不变，分别唱C3 … C3与G3 … G3来核对转位低音。在转用遍中恢复每个写出音组，重点聆听低音sol3→do3与顶声部mi4→sol3，不要把和声听成一条被摊平的旋律。

修正低音sol3→do3与顶声部mi4→sol3时，只循环最后两个写出事件，直到两条外声连续两次同时到达。不中断地录下两遍8 拍；只有C3 … C3与G3 … G3都在写出音区同时到达每个边界时才保留。先把C → C/E → C/G → C在转用遍中完整录一遍，再用转位低音检查第一个边界；只循环修正该处两次，随后回到原速度和音区，不要改动其他事件。最后复核转用遍中的转位低音。
