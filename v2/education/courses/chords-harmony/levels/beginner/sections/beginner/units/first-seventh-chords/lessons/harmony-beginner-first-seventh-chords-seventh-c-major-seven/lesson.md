# Cmaj7を組み立てる

ルート優先の回でCmaj7を確かめ、ルートで長7度を支え、68 BPMのアルペジオでその色を明瞭に保ちます。7度の色を「7度を加えると4音になり、トライアドのクオリティと7度の種類が一緒に安定、方向、開放感を形作ります」という原理と結び、他の構成音を加える前に決め手の音程を聞き取ります。アルペジオで3 回のアタックを行い、音域と強弱を固定して、長7度を7度の色に照らして判断します。

ルート優先の回では保持したルートの上で長7度を歌い、同じ綴りのままコードを1音ずつ組み直します。長7度が隠れたら、覆う音だけを弱め、ボイシングを広げたりルートを強く叩いたりしません。アルペジオを3回続け、長7度が明瞭に始まり、全構成音がそろって入り、離鍵もきれいな場合だけ残します。最後にルート優先の回の7度の色を確認します。

:::checkpoint Cmaj7をルートから組み立て、各音程を言ってから完成したコードを68 BPMで3回弾く。

# 构建Cmaj7

在根音优先遍中检查Cmaj7；根音支撑大七音，68 BPM的琶音让这种色彩保持清楚。把七音色彩与“七音增加第四个和弦音”这个原理联系起来；加入其余和弦音之前，决定性质的音程必须清楚可听。用琶音完成3 次起奏，固定音区与力度，再依据七音色彩判断大七音是否清楚。在根音优先遍中对着持续根音唱大七音，再保持同一和弦拼写，逐音重建整个和弦。

若大七音被遮住，只减轻覆盖它的和弦音；不要扩开排列，也不要更用力地击打根音。连续完成三次琶音；只有大七音起始清楚、所有和弦音同时到达且收音干净时才保留。先把Cmaj7在根音优先遍中完整录一遍，再用七音色彩检查第一个边界；只循环修正该处两次，随后回到原速度和音区，不要改动其他事件。最后复核根音优先遍中的七音色彩。
