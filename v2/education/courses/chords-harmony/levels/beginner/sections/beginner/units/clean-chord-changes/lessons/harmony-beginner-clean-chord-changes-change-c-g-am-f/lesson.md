# C → G → Am → Fを弾く

境界修正の回でC → G → Am → Fを1回読み、ドをトニックにしたトニック (I)–ドミナント (V)–サブメディアント (vi)–サブドミナント (IV)の4 回の変化を8 拍に収めます。切れ目のない変化を「滑らかな変更は安定したカウントと小さな動きから始まり、両コードがそろって鳴ってから速度を上げます」という原理と結び、再生前に各機能が次の低音ルートへ向くことを予測します。I V vi IVの各コードを2 拍数え、切れ目のない変化を基準に4 回の変化を均等にして、vi → IVを急ぎません。
