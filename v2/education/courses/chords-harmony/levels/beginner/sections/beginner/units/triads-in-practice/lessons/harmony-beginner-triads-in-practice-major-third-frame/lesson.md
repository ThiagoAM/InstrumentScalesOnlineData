# Vergleiche 1–3–5 / 1–♭3–5

Höre 1–3–5 / 1–♭3–5 einmal im Oberstimmendurchgang; halte Grundton, Lage, Lautstärke und Anschlag fest, während A (Stufen 1 3 5) gegenüber B (Halbtöne 0 3 7; Stufen 1 2 3) wechselt. Verbinde Dreiklangsaufbau mit diesem Prinzip: Der Grundton benennt den Akkord, die Terz bestimmt Dur oder Moll und die Quinte bildet den äußeren Rahmen; der kontrollierte Unterschied erklärt die verschiedene Funktion oder Farbe von A und B. Wechsle A, eins–drei–fünf, und B, Prime–kleine Terz–reine Quinte, viermal bei 68 BPM; lass mit Dreiklangsaufbau einen stillen Schlag zwischen den Seiten.

Benenne A (Stufen 1 3 5) gegenüber B (Halbtöne 0 3 7; Stufen 1 2 3) im Oberstimmendurchgang und singe den ersten veränderten Ton, bevor das A- oder B-Etikett erscheint. Repariere eine unsichere Antwort, indem du eins–drei–fünf von Prime–kleine Terz–reine Quinte isolierst und vor dem neuen Vergleich Lautstärke und Pause gleichsetzt. Behalte die letzten zwei Blindversuche nur mit richtigen Etiketten und einer Begründung über A (Stufen 1 3 5) gegenüber B (Halbtöne 0 3 7; Stufen 1 2 3) statt Lautstärke oder Lage. Nutze Dreiklangsaufbau als letzte Prüfung im Oberstimmendurchgang.

# 1–3–5 / 1–♭3–5を比べる

上声優先の回で1–3–5 / 1–♭3–5を1回聴き、共通のルート、音域、音量、タッチを固定してA（度数 1 3 5）とB（半音 0 3 7; 度数 1 2 3）の差だけを変えます。トライアドの構成音を「ルートがコード名を決め、3度がメジャーかマイナーを決め、5度が外枠を支えます」という原理と結び、制御した差によってAとBの機能または色が違う理由を説明します。Aの一–三–五とBのユニゾン–短3度–完全5度を68 BPMで4回交互に聴き、トライアドの構成音を基準に両側の間へ1拍の無音を置きます。

上声優先の回でA（度数 1 3 5）とB（半音 0 3 7; 度数 1 2 3）の差を言葉にし、AまたはBのラベルを見る前に最初の変化音を歌います。答えが曖昧なら一–三–五とユニゾン–短3度–完全5度を分け、同じ音量と1拍の無音を戻してから再び比較します。最後の2回はブラインドで行い、両方のラベルが正しく、理由が音量や音域ではなくA（度数 1 3 5）とB（半音 0 3 7; 度数 1 2 3）の差を示した場合だけ残します。最後に上声優先の回のトライアドの構成音を確認します。

# 比较1–3–5 / 1–♭3–5

在顶声部优先遍中听1–3–5 / 1–♭3–5一遍；固定共同根音、音区、音量与触键，只让A（音级 1 3 5）与B（半音 0 3 7; 音级 1 2 3）的差异发生变化。把三和弦构成与“根音决定和弦名称，三音决定大调或小调性质，五音形成外部框架”这个原理联系起来；受控差异必须说明A与B为何具有不同功能或色彩。以68 BPM把A的一–三–五与B的同度–小三度–纯五度交替四遍；依据三和弦构成在两边之间留一拍完整安静。

在顶声部优先遍中说出A（音级 1 3 5）与B（半音 0 3 7; 音级 1 2 3）的差异，并在揭示A或B标签之前唱出第一个变化音。若答案不确定，先把一–三–五与同度–小三度–纯五度分离，再恢复相同音量与一拍安静，然后重新比较。最后两次采用盲听；只有两个标签都正确，而且口头理由指出A（音级 1 3 5）与B（半音 0 3 7; 音级 1 2 3）的差异而不是音量或音区时才保留。最后复核顶声部优先遍中的三和弦构成。
