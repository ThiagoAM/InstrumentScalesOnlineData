# G7 → Cを解決する

低音主導の回でG7 → Cを1回読み、ドをトニックにしたドミナント (V)–トニック (I)の2 回の変化を6 拍に収めます。7度の色を「7度を加えると4音になり、トライアドのクオリティと7度の種類が一緒に安定、方向、開放感を形作ります」という原理と結び、再生前に各機能が次の低音ルートへ向くことを予測します。V Iの各コードを3 拍数え、7度の色を基準に2 回の変化を均等にして、V → Iを急ぎません。

低音主導の回で低音ルートを歌い、V → Iを一つの到着として聴いて、最後のコードの機能を言います。低音主導の回で到着の遅れを直すには、V → Iを各コード3 拍で2回反復し、止めずに前の機能を戻します。低音主導の回では、72 BPMで2回弾き、各変化が均等で、V → Iの働きを正答した場合だけ残します。最後に低音主導の回の7度の色を確認します。
