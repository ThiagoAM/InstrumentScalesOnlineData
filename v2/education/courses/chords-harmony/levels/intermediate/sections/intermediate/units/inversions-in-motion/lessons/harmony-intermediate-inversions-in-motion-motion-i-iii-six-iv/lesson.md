# I–iii6–IV6を追う

無音予測の回でI–iii6–IV6を1回読み、ピアノの3 ボイシングを6 拍保ち、低音C3 → B2 → A2と上声G3 → G3 → F3を追います。歌える転回形の低音を「スラッシュ表記は先にコード、後に低音を示し、選んだ低音がルート同士を小さく明確な動きでつなぎます」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで3 ボイシングをすべて弾き、音域を変えずC3 → B2 → A2とG3 → G3 → F3を別々に歌って歌える転回形の低音を確かめます。

無音予測の回で各記譜グループを戻し、一本の旋律としてではなく、低音シ2→ラ2と上声ソ3→ファ3を重点的に聴きます。低音シ2→ラ2と上声ソ3→ファ3を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。6 拍を止めずに2回録音し、C3 → B2 → A2とG3 → G3 → F3が記譜音域の各境界へ同時に着く場合だけ残します。最後に無音予測の回の歌える転回形の低音を確認します。

# 跟随I–iii6–IV6

在无声预测遍中把I–iii6–IV6读一遍；钢琴在6 拍内保持3 和弦排列，低音为C3 → B2 → A2，顶声部为G3 → G3 → F3。把可歌转位低音与“斜线和弦先写和弦、后写低音”这个原理联系起来；方括号内各音同时开始，两条外声路线则揭示方向。以66 BPM弹完3 和弦排列，再保持音区不变，分别唱C3 → B2 → A2与G3 → G3 → F3来核对可歌转位低音。在无声预测遍中恢复每个写出音组，重点聆听低音si2→la2与顶声部sol3→fa3，不要把和声听成一条被摊平的旋律。
