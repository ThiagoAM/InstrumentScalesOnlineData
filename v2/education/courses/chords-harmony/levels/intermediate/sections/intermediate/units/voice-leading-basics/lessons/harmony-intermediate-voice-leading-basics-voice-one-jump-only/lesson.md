# Connect Dm → G → C

Trace Dm → G → C in the bass-led pass; 3 written voicings span 6 beats through bass re3 → do3, top la3 → sol3. Align bass re3 → do3 with top la3 → sol3; attack each bracket together; judge distance between individual voices. Set economical voice motion at 66 BPM; sing re3 → do3 below la3 → sol3, then play 3 written voicings. Keep bass re3 → do3, top la3 → sol3 as separate outer lines through the bass-led pass; judge small singable voice motion.

Trace one outer voice through Dm → G → C during the bass-led pass; sing it alone, check economical voice motion at each chord boundary, and add the remaining tones only after the line connects without a reset. Reconnect economical voice motion: repeat the closing boundary at bass re3 → do3, top la3 → sol3; coordinate both arrivals twice. Retain a coordinated outer-voice arrival; retain a pair of 6-beat passes aligning bass re3 → do3, top la3 → sol3 at every change without changing register.

:::checkpoint Connect Dm → G → C three times at 66 BPM without a gap and name one held or stepwise voice afterward.

# Conecte Dm → G → C

Leia Dm → G → C uma vez na passagem guiada pelo baixo; o piano sustenta 3 aberturas por 6 tempos, com baixo D3 → D3 → C3 e topo A3 → B3 → G3. Relacione movimento econômico das vozes a este princípio: A condução suave mede a distância percorrida por cada nota, não a distância entre as fundamentais; as notas entre colchetes começam juntas enquanto os caminhos externos revelam direção. Toque todas as 3 aberturas a 66 BPM e cante D3 → D3 → C3 e A3 → B3 → G3 separadamente para conferir movimento econômico das vozes sem mudar o registro.

Corrija baixo ré3 → dó3 e topo si3 → sol3 repetindo apenas os dois eventos finais até as duas vozes externas chegarem juntas duas vezes. Guarde duas tomadas contínuas de 6 tempos apenas quando D3 → D3 → C3 e A3 → B3 → G3 alcançarem cada fronteira juntos no registro escrito. Use movimento econômico das vozes como verificação final da passagem guiada pelo baixo.

:::checkpoint Conecte Dm → G → C três vezes a 66 BPM sem lacuna e depois diga uma voz mantida ou conjunta.

# Conecta Dm → G → C

Lee Dm → G → C una vez en la pasada guiada por el bajo; el piano mantiene 3 disposiciones durante 6 pulsos, con bajo D3 → D3 → C3 y voz superior A3 → B3 → G3. Relaciona movimiento económico de voces con este principio: La conducción suave mide la distancia recorrida por cada nota y no la distancia entre fundamentales; las notas entre corchetes empiezan juntas mientras las líneas exteriores revelan dirección. Toca todas las 3 disposiciones a 66 BPM y canta D3 → D3 → C3 y A3 → B3 → G3 por separado para comprobar movimiento económico de voces sin cambiar de registro.

Corrige bajo re3 → do3 y voz superior si3 → sol3 repitiendo solo los dos eventos finales hasta que ambas voces exteriores lleguen juntas dos veces. Conserva dos tomas continuas de 6 pulsos solo cuando D3 → D3 → C3 y A3 → B3 → G3 alcancen juntos cada límite en el registro escrito. Usa movimiento económico de voces como comprobación final de la pasada guiada por el bajo.

:::checkpoint Conecta Dm → G → C tres veces a 66 BPM sin hueco y después nombra una voz mantenida o conjunta.

# Verbinde Dm → G → C

Lies Dm → G → C einmal im bassgeführter Durchgang; das Klavier hält 3 Lagen über 6 Schläge, mit Bass D3 → D3 → C3 und Oberstimme A3 → B3 → G3. Verbinde sparsame Stimmbewegung mit diesem Prinzip: Glatte Stimmführung misst den Weg einzelner Töne, nicht den Abstand zwischen Akkordgrundtönen; Klammernoten beginnen gemeinsam, während die Außenwege Richtung zeigen. Spiele alle 3 Lagen bei 66 BPM und singe D3 → D3 → C3 sowie A3 → B3 → G3 getrennt, um sparsame Stimmbewegung ohne Lagenwechsel zu prüfen.

Stelle im bassgeführter Durchgang jede notierte Gruppe wieder her und höre gezielt auf Bass D3 → C3 und Oberstimme H3 → G3, nicht auf eine abgeflachte Einzelmelodie. Repariere Bass D3 → C3 und Oberstimme H3 → G3, indem du nur die letzten zwei Ereignisse wiederholst, bis beide Außenstimmen zweimal gemeinsam ankommen. Behalte zwei ununterbrochene Durchgänge über 6 Schläge nur, wenn D3 → D3 → C3 und A3 → B3 → G3 jede Grenze gemeinsam in der notierten Lage erreichen. Nutze sparsame Stimmbewegung als letzte Prüfung im bassgeführter Durchgang.

:::checkpoint Verbinde Dm → G → C dreimal bei 66 BPM ohne Lücke und nenne danach eine gehaltene oder schrittweise Stimme.

# Dm → G → Cをつなぐ

低音主導の回でDm → G → Cを1回読み、ピアノの3 ボイシングを6 拍保ち、低音D3 → D3 → C3と上声A3 → B3 → G3を追います。声部の無駄のない動きを「滑らかなボイス・リーディングはコードのルート間ではなく、各音が進む距離で考えます」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで3 ボイシングをすべて弾き、音域を変えずD3 → D3 → C3とA3 → B3 → G3を別々に歌って声部の無駄のない動きを確かめます。

低音主導の回で各記譜グループを戻し、一本の旋律としてではなく、低音レ3→ド3と上声シ3→ソ3を重点的に聴きます。低音レ3→ド3と上声シ3→ソ3を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。6 拍を止めずに2回録音し、D3 → D3 → C3とA3 → B3 → G3が記譜音域の各境界へ同時に着く場合だけ残します。最後に低音主導の回の声部の無駄のない動きを確認します。

:::checkpoint Dm → G → Cを66 BPMで隙間なく3回つなぎ、保った声部または順次進行を一つ言う。

# 连接Dm → G → C

在低音主导遍中把Dm → G → C读一遍；钢琴在6 拍内保持3 和弦排列，低音为D3 → D3 → C3，顶声部为A3 → B3 → G3。把精简声部移动与“平滑声部进行衡量的是各个音移动的距离，而不是和弦根音之间的距离”这个原理联系起来；方括号内各音同时开始，两条外声路线则揭示方向。以66 BPM弹完3 和弦排列，再保持音区不变，分别唱D3 → D3 → C3与A3 → B3 → G3来核对精简声部移动。

在低音主导遍中恢复每个写出音组，重点聆听低音re3→do3与顶声部si3→sol3，不要把和声听成一条被摊平的旋律。修正低音re3→do3与顶声部si3→sol3时，只循环最后两个写出事件，直到两条外声连续两次同时到达。不中断地录下两遍6 拍；只有D3 → D3 → C3与A3 → B3 → G3都在写出音区同时到达每个边界时才保留。最后复核低音主导遍中的精简声部移动。

:::checkpoint 以66 BPM无间隙连接Dm → G → C三遍，随后说出一个保持或级进声部。
