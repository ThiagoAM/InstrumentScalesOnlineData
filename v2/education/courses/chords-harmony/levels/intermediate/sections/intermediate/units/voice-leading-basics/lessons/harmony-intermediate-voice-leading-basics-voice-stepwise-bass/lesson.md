# Follow C → G/B → Am

Predict C → G/B → Am in the silent-prediction pass; 3 written voicings span 6 beats through bass do3 → la2, top sol3 → mi3. Align bass do3 → la2 with top sol3 → mi3; attack each bracket together; judge distance between individual voices. Test economical voice motion at 66 BPM; sing do3 → la2 below sol3 → mi3, then play 3 written voicings. Keep bass do3 → la2, top sol3 → mi3 as separate outer lines through the silent-prediction pass; judge small singable voice motion.

Predict the hardest boundary in C → G/B → Am before the silent-prediction pass; check that prediction against playback, use economical voice motion to name what actually changed, and rehearse only the smaller span before another full pass. Revise economical voice motion: repeat the closing boundary at bass do3 → la2, top sol3 → mi3; coordinate both arrivals twice. Confirm a coordinated outer-voice arrival; retain a pair of 6-beat passes aligning bass do3 → la2, top sol3 → mi3 at every change without changing register.

:::checkpoint Sing the lowest or named moving voice in C → G/B → Am, then play the written sequence three times at 66 BPM.

# Acompanhe C → G/B → Am

Leia C → G/B → Am uma vez na passagem de previsão silenciosa; o piano sustenta 3 aberturas por 6 tempos, com baixo C3 → B2 → A2 e topo G3 → G3 → E3. Relacione movimento econômico das vozes a este princípio: A condução suave mede a distância percorrida por cada nota, não a distância entre as fundamentais; as notas entre colchetes começam juntas enquanto os caminhos externos revelam direção. Toque todas as 3 aberturas a 66 BPM e cante C3 → B2 → A2 e G3 → G3 → E3 separadamente para conferir movimento econômico das vozes sem mudar o registro.

Corrija baixo si2 → lá2 e topo sol3 → mi3 repetindo apenas os dois eventos finais até as duas vozes externas chegarem juntas duas vezes. Guarde duas tomadas contínuas de 6 tempos apenas quando C3 → B2 → A2 e G3 → G3 → E3 alcançarem cada fronteira juntos no registro escrito. Use movimento econômico das vozes como verificação final da passagem de previsão silenciosa.

:::checkpoint Cante a voz mais grave ou indicada em C → G/B → Am e toque a sequência escrita três vezes a 66 BPM.

# Sigue C → G/B → Am

Lee C → G/B → Am una vez en la pasada de predicción silenciosa; el piano mantiene 3 disposiciones durante 6 pulsos, con bajo C3 → B2 → A2 y voz superior G3 → G3 → E3. Relaciona movimiento económico de voces con este principio: La conducción suave mide la distancia recorrida por cada nota y no la distancia entre fundamentales; las notas entre corchetes empiezan juntas mientras las líneas exteriores revelan dirección. Toca todas las 3 disposiciones a 66 BPM y canta C3 → B2 → A2 y G3 → G3 → E3 por separado para comprobar movimiento económico de voces sin cambiar de registro.

Corrige bajo si2 → la2 y voz superior sol3 → mi3 repitiendo solo los dos eventos finales hasta que ambas voces exteriores lleguen juntas dos veces. Conserva dos tomas continuas de 6 pulsos solo cuando C3 → B2 → A2 y G3 → G3 → E3 alcancen juntos cada límite en el registro escrito. Usa movimiento económico de voces como comprobación final de la pasada de predicción silenciosa.

:::checkpoint Canta la voz más grave o indicada de C → G/B → Am y toca la secuencia escrita tres veces a 66 BPM.

# Verfolge C → G/B → Am

Lies C → G/B → Am einmal im stiller Vorhersagedurchgang; das Klavier hält 3 Lagen über 6 Schläge, mit Bass C3 → B2 → A2 und Oberstimme G3 → G3 → E3. Verbinde sparsame Stimmbewegung mit diesem Prinzip: Glatte Stimmführung misst den Weg einzelner Töne, nicht den Abstand zwischen Akkordgrundtönen; Klammernoten beginnen gemeinsam, während die Außenwege Richtung zeigen. Spiele alle 3 Lagen bei 66 BPM und singe C3 → B2 → A2 sowie G3 → G3 → E3 getrennt, um sparsame Stimmbewegung ohne Lagenwechsel zu prüfen.

Stelle im stiller Vorhersagedurchgang jede notierte Gruppe wieder her und höre gezielt auf Bass H2 → A2 und Oberstimme G3 → E3, nicht auf eine abgeflachte Einzelmelodie. Repariere Bass H2 → A2 und Oberstimme G3 → E3, indem du nur die letzten zwei Ereignisse wiederholst, bis beide Außenstimmen zweimal gemeinsam ankommen. Behalte zwei ununterbrochene Durchgänge über 6 Schläge nur, wenn C3 → B2 → A2 und G3 → G3 → E3 jede Grenze gemeinsam in der notierten Lage erreichen. Nutze sparsame Stimmbewegung als letzte Prüfung im stiller Vorhersagedurchgang.

:::checkpoint Singe die tiefste oder benannte bewegte Stimme in C → G/B → Am und spiele die notierte Folge dreimal bei 66 BPM.

# C → G/B → Amを追う

無音予測の回でC → G/B → Amを1回読み、ピアノの3 ボイシングを6 拍保ち、低音C3 → B2 → A2と上声G3 → G3 → E3を追います。声部の無駄のない動きを「滑らかなボイス・リーディングはコードのルート間ではなく、各音が進む距離で考えます」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで3 ボイシングをすべて弾き、音域を変えずC3 → B2 → A2とG3 → G3 → E3を別々に歌って声部の無駄のない動きを確かめます。

無音予測の回で各記譜グループを戻し、一本の旋律としてではなく、低音シ2→ラ2と上声ソ3→ミ3を重点的に聴きます。低音シ2→ラ2と上声ソ3→ミ3を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。6 拍を止めずに2回録音し、C3 → B2 → A2とG3 → G3 → E3が記譜音域の各境界へ同時に着く場合だけ残します。最後に無音予測の回の声部の無駄のない動きを確認します。

:::checkpoint C → G/B → Amの最低声部または指定された動く声部を歌い、書かれた並びを66 BPMで3回弾く。
:::locale zh-Hans
# 跟随C → G/B → Am

在无声预测遍中把C → G/B → Am读一遍；钢琴在6 拍内保持3 和弦排列，低音为C3 → B2 → A2，顶声部为G3 → G3 → E3。把精简声部移动与“平滑声部进行衡量的是各个音移动的距离，而不是和弦根音之间的距离”这个原理联系起来；方括号内各音同时开始，两条外声路线则揭示方向。以66 BPM弹完3 和弦排列，再保持音区不变，分别唱C3 → B2 → A2与G3 → G3 → E3来核对精简声部移动。

在无声预测遍中恢复每个写出音组，重点聆听低音si2→la2与顶声部sol3→mi3，不要把和声听成一条被摊平的旋律。修正低音si2→la2与顶声部sol3→mi3时，只循环最后两个写出事件，直到两条外声连续两次同时到达。不中断地录下两遍6 拍；只有C3 → B2 → A2与G3 → G3 → E3都在写出音区同时到达每个边界时才保留。最后复核无声预测遍中的精简声部移动。

:::checkpoint 唱出C → G/B → Am的最低声部或指定移动声部，再以66 BPM弹奏写出的序列三遍。
