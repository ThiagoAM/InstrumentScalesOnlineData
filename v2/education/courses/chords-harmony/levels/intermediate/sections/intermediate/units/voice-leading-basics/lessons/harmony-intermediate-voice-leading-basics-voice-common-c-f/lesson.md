# Keep C → F/C with common C

Build C → F/C with common C in the outer-voice pass; 2 written voicings span 4 beats through bass do4 → do4, top sol4 → la4. Align bass do4 → do4 with top sol4 → la4; attack each bracket together; judge distance between individual voices. Set economical voice motion at 66 BPM; sing do4 → do4 below sol4 → la4, then play 2 written voicings. Keep bass do4 → do4, top sol4 → la4 as separate outer lines through the outer-voice pass; judge small singable voice motion.

Play C → F/C with common C once without stopping during the outer-voice pass; write down the first audible problem in economical voice motion, repair only that moment, and make a second take without changing register or dynamics. Rebalance economical voice motion: repeat the closing boundary at bass do4 → do4, top sol4 → la4; coordinate both arrivals twice. Keep a coordinated outer-voice arrival; retain a pair of 4-beat passes aligning bass do4 → do4, top sol4 → la4 at every change without changing register.

:::checkpoint Hold the specified common or pedal tone through C → F/C with common C; repeat three times without reattacking that voice.

# Mantenha C → F/C com C comum

Leia C → F/C com C comum uma vez na passagem das vozes externas; o piano sustenta 2 aberturas por 4 tempos, com baixo C4 → C4 e topo G4 → A4. Relacione movimento econômico das vozes a este princípio: A condução suave mede a distância percorrida por cada nota, não a distância entre as fundamentais; as notas entre colchetes começam juntas enquanto os caminhos externos revelam direção. Toque todas as 2 aberturas a 66 BPM e cante C4 → C4 e G4 → A4 separadamente para conferir movimento econômico das vozes sem mudar o registro.

Corrija baixo dó4 → dó4 e topo sol4 → lá4 repetindo apenas os dois eventos finais até as duas vozes externas chegarem juntas duas vezes. Guarde duas tomadas contínuas de 4 tempos apenas quando C4 → C4 e G4 → A4 alcançarem cada fronteira juntos no registro escrito. Use movimento econômico das vozes como verificação final da passagem das vozes externas.

:::checkpoint Sustente a nota comum ou pedal indicada em C → F/C com C comum; repita três vezes sem reatacar essa voz.

# Mantén C → F/C con C común

Lee C → F/C con C común una vez en la pasada de voces exteriores; el piano mantiene 2 disposiciones durante 4 pulsos, con bajo C4 → C4 y voz superior G4 → A4. Relaciona movimiento económico de voces con este principio: La conducción suave mide la distancia recorrida por cada nota y no la distancia entre fundamentales; las notas entre corchetes empiezan juntas mientras las líneas exteriores revelan dirección. Toca todas las 2 disposiciones a 66 BPM y canta C4 → C4 y G4 → A4 por separado para comprobar movimiento económico de voces sin cambiar de registro.

Corrige bajo do4 → do4 y voz superior sol4 → la4 repitiendo solo los dos eventos finales hasta que ambas voces exteriores lleguen juntas dos veces. Conserva dos tomas continuas de 4 pulsos solo cuando C4 → C4 y G4 → A4 alcancen juntos cada límite en el registro escrito. Usa movimiento económico de voces como comprobación final de la pasada de voces exteriores.

:::checkpoint Mantén la nota común o pedal indicada en C → F/C con C común; repite tres veces sin volver a atacar esa voz.

# Halte C → F/C mit gemeinsamem C

Lies C → F/C mit gemeinsamem C einmal im Außenstimmendurchgang; das Klavier hält 2 Lagen über 4 Schläge, mit Bass C4 → C4 und Oberstimme G4 → A4. Verbinde sparsame Stimmbewegung mit diesem Prinzip: Glatte Stimmführung misst den Weg einzelner Töne, nicht den Abstand zwischen Akkordgrundtönen; Klammernoten beginnen gemeinsam, während die Außenwege Richtung zeigen. Spiele alle 2 Lagen bei 66 BPM und singe C4 → C4 sowie G4 → A4 getrennt, um sparsame Stimmbewegung ohne Lagenwechsel zu prüfen.

Stelle im Außenstimmendurchgang jede notierte Gruppe wieder her und höre gezielt auf Bass C4 → C4 und Oberstimme G4 → A4, nicht auf eine abgeflachte Einzelmelodie. Repariere Bass C4 → C4 und Oberstimme G4 → A4, indem du nur die letzten zwei Ereignisse wiederholst, bis beide Außenstimmen zweimal gemeinsam ankommen. Behalte zwei ununterbrochene Durchgänge über 4 Schläge nur, wenn C4 → C4 und G4 → A4 jede Grenze gemeinsam in der notierten Lage erreichen. Nutze sparsame Stimmbewegung als letzte Prüfung im Außenstimmendurchgang.

:::checkpoint Halte den gemeinsamen oder Pedalton durch C → F/C mit gemeinsamem C und wiederhole dreimal, ohne diese Stimme neu anzuschlagen.

# 共通音Cを保つC → F/Cを保つ

外声優先の回で共通音Cを保つC → F/Cを1回読み、ピアノの2 ボイシングを4 拍保ち、低音C4 → C4と上声G4 → A4を追います。声部の無駄のない動きを「滑らかなボイス・リーディングはコードのルート間ではなく、各音が進む距離で考えます」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで2 ボイシングをすべて弾き、音域を変えずC4 → C4とG4 → A4を別々に歌って声部の無駄のない動きを確かめます。

外声優先の回で各記譜グループを戻し、一本の旋律としてではなく、低音ド4→ド4と上声ソ4→ラ4を重点的に聴きます。低音ド4→ド4と上声ソ4→ラ4を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。4 拍を止めずに2回録音し、C4 → C4とG4 → A4が記譜音域の各境界へ同時に着く場合だけ残します。最後に外声優先の回の声部の無駄のない動きを確認します。

:::checkpoint 共通音Cを保つC → F/Cの指定された共通音またはペダル音を保ち、その声部を弾き直さず3回繰り返す。

# 保持保留共同音C的C → F/C

在外声部优先遍中把保留共同音C的C → F/C读一遍；钢琴在4 拍内保持2 和弦排列，低音为C4 → C4，顶声部为G4 → A4。把精简声部移动与“平滑声部进行衡量的是各个音移动的距离，而不是和弦根音之间的距离”这个原理联系起来；方括号内各音同时开始，两条外声路线则揭示方向。以66 BPM弹完2 和弦排列，再保持音区不变，分别唱C4 → C4与G4 → A4来核对精简声部移动。

在外声部优先遍中恢复每个写出音组，重点聆听低音do4→do4与顶声部sol4→la4，不要把和声听成一条被摊平的旋律。修正低音do4→do4与顶声部sol4→la4时，只循环最后两个写出事件，直到两条外声连续两次同时到达。不中断地录下两遍4 拍；只有C4 → C4与G4 → A4都在写出音区同时到达每个边界时才保留。最后复核外声部优先遍中的精简声部移动。

:::checkpoint 在保留共同音C的C → F/C中保持指定共同音或持续音；重复三遍且不重新起奏该声部。
