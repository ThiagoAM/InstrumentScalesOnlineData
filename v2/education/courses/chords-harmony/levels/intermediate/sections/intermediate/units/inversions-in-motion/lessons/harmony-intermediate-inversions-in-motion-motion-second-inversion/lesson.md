# C/G → Gを比べる

外声優先の回でC/G → Gを1回読み、ピアノの2 ボイシングを4 拍保ち、低音G2 → G2と上声E3 → D3を追います。歌える転回形の低音を「スラッシュ表記は先にコード、後に低音を示し、選んだ低音がルート同士を小さく明確な動きでつなぎます」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで2 ボイシングをすべて弾き、音域を変えずG2 → G2とE3 → D3を別々に歌って歌える転回形の低音を確かめます。

外声優先の回で各記譜グループを戻し、一本の旋律としてではなく、低音ソ2→ソ2と上声ミ3→レ3を重点的に聴きます。低音ソ2→ソ2と上声ミ3→レ3を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。4 拍を止めずに2回録音し、G2 → G2とE3 → D3が記譜音域の各境界へ同時に着く場合だけ残します。最後に外声優先の回の歌える転回形の低音を確認します。

# 比较C/G → G

在外声部优先遍中把C/G → G读一遍；钢琴在4 拍内保持2 和弦排列，低音为G2 → G2，顶声部为E3 → D3。把可歌转位低音与“斜线和弦先写和弦、后写低音”这个原理联系起来；方括号内各音同时开始，两条外声路线则揭示方向。以66 BPM弹完2 和弦排列，再保持音区不变，分别唱G2 → G2与E3 → D3来核对可歌转位低音。在外声部优先遍中恢复每个写出音组，重点聆听低音sol2→sol2与顶声部mi3→re3，不要把和声听成一条被摊平的旋律。

修正低音sol2→sol2与顶声部mi3→re3时，只循环最后两个写出事件，直到两条外声连续两次同时到达。不中断地录下两遍4 拍；只有G2 → G2与E3 → D3都在写出音区同时到达每个边界时才保留。先把C/G → G在外声部优先遍中完整录一遍，再用可歌转位低音检查第一个边界；只循环修正该处两次，随后回到原速度和音区，不要改动其他事件。最后复核外声部优先遍中的可歌转位低音。
