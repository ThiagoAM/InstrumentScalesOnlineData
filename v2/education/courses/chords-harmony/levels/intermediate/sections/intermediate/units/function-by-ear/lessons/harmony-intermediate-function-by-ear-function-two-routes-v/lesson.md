# ii–V / IV–Vを比べる

上声優先の回でii–V / IV–Vを1回読み、A スーパートニック (ii)–ドミナント (V) / B サブドミナント (IV)–ドミナント (V)を一本の連鎖ではなく二つの別案として扱います。トニック–プレドミナント–ドミナント機能を「機能は楽句内の役割を示します」という原理と結び、ii VとIV Vの到着先を比べます。Aは2 コードを4 拍、Bは2 コードを4 拍で弾き、トニック–プレドミナント–ドミナント機能を基準に二つの時間軸を分けます。

上声優先の回で各経路の低音ルートを歌い、ii → VからIV → Vへ移る前に1拍の無音を置きます。到着先が曖昧なら、ii → VとIV → Vを同じコード長で別々に反復してから再び比較します。時間を省かずに2回ブラインド比較し、どの終止が楽句を閉じる、遅らせる、転じるか正答した場合だけ残します。最後に上声優先の回のトニック–プレドミナント–ドミナント機能を確認します。

在顶声部优先遍中分别唱两条路线的低音根音；从ii → V换到IV → V之前留一拍完整安静。若到达位置模糊，先用相同和弦时值分别循环ii → V与IV → V，再重新比较两边。完成两次盲听比较；只有两边时值都完整，而且能正确说出哪个结尾结束、延后或转向乐句时才保留。最后复核顶声部优先遍中的主–下属准备–属功能。
