En la pasada desde el pulso, conserva dos tomas a 72 BPM solo cuando cada cambio quede igual y digas si vii → I cierra, retrasa o redirige. # V–vii°–Iを聴き分ける

拍優先の回でV–vii°–Iを1回読み、ドをトニックにしたドミナント (V)–導音機能 (vii)–トニック (I)の3 回の変化を6 拍に収めます。トニック–プレドミナント–ドミナント機能を「機能は楽句内の役割を示します」という原理と結び、再生前に各機能が次の低音ルートへ向くことを予測します。V vii Iの各コードを2 拍数え、トニック–プレドミナント–ドミナント機能を基準に3 回の変化を均等にして、vii → Iを急ぎません。

拍優先の回で低音ルートを歌い、vii → Iを一つの到着として聴いて、最後のコードの機能を言います。拍優先の回で到着の遅れを直すには、vii → Iを各コード2 拍で2回反復し、止めずに前の機能を戻します。拍優先の回では、72 BPMで2回弾き、各変化が均等で、vii → Iの働きを正答した場合だけ残します。最後に拍優先の回のトニック–プレドミナント–ドミナント機能を確認します。
