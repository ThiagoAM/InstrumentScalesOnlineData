Leia C–G/B–Am uma vez na passagem de contraste; o piano sustenta 3 aberturas por 6 tempos, com baixo C3 → B2 → A2 e topo G3 → G3 → E3. Relacione evidência da transcrição a este princípio: A transcrição fica confiável quando baixo, qualidade, função, inversão, cadência e textura são conferidos nessa ordem; as notas entre colchetes começam juntas enquanto os caminhos externos revelam direção. Toque todas as 3 aberturas a 66 BPM e cante C3 → B2 → A2 e G3 → G3 → E3 separadamente para conferir evidência da transcrição sem mudar o registro.

# C–G/B–Amを聴き分ける

対比優先の回でC–G/B–Amを1回読み、ピアノの3 ボイシングを6 拍保ち、低音C3 → B2 → A2と上声G3 → G3 → E3を追います。採譜の根拠を「低音、クオリティ、機能、転回形、カデンツ、テクスチャの順に確認すると採譜が安定します」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで3 ボイシングをすべて弾き、音域を変えずC3 → B2 → A2とG3 → G3 → E3を別々に歌って採譜の根拠を確かめます。

対比優先の回で各記譜グループを戻し、一本の旋律としてではなく、低音シ2→ラ2と上声ソ3→ミ3を重点的に聴きます。低音シ2→ラ2と上声ソ3→ミ3を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。6 拍を止めずに2回録音し、C3 → B2 → A2とG3 → G3 → E3が記譜音域の各境界へ同時に着く場合だけ残します。最後に対比優先の回の採譜の根拠を確認します。

在对比遍中把C–G/B–Am读一遍；钢琴在6 拍内保持3 和弦排列，低音为C3 → B2 → A2，顶声部为G3 → G3 → E3。把听写依据与“按低音、性质、功能、转位、终止式、织体的顺序核对，听写会更可靠”这个原理联系起来；方括号内各音同时开始，两条外声路线则揭示方向。以66 BPM弹完3 和弦排列，再保持音区不变，分别唱C3 → B2 → A2与G3 → G3 → E3来核对听写依据。在对比遍中恢复每个写出音组，重点聆听低音si2→la2与顶声部sol3→mi3，不要把和声听成一条被摊平的旋律。
