# Connect C → G/B

Read C → G/B in the root-first pass; 2 written voicings span 4 beats through bass do3 → ti2, top sol3 → sol3. Match bass do3 → ti2 with top sol3 → sol3; begin each bracket together; match bass-line choice through inversions. Mark singable inversion bass at 66 BPM; play 2 written voicings, then sing do3 → ti2 below sol3 → sol3. Hear bass do3 → ti2, top sol3 → sol3 in the root-first pass, never as one melody; track a singable inverted bass.

Make one diagnostic recording of C → G/B in the root-first pass; on playback, mark the first moment where singable inversion bass succeeds or fails, rehearse that moment twice, and return to the complete example. Correct singable inversion bass: loop the last events at bass do3 → ti2, top sol3 → sol3; align both arrivals twice. For smooth weight across chord changes, keep two 4-beat takes with bass do3 → ti2, top sol3 → sol3 aligned at every change in the written register.

# Conecte C → G/B

Leia C → G/B uma vez na passagem pela fundamental; o piano sustenta 2 aberturas por 4 tempos, com baixo C3 → B2 e topo G3 → G3. Relacione baixo cantável da inversão a este princípio: A cifra com barra nomeia primeiro o acorde e depois o baixo; as notas entre colchetes começam juntas enquanto os caminhos externos revelam direção. Toque todas as 2 aberturas a 66 BPM e cante C3 → B2 e G3 → G3 separadamente para conferir baixo cantável da inversão sem mudar o registro.

Restaure cada grupo escrito durante a passagem pela fundamental e ouça especificamente baixo dó3 → si2 e topo sol3 → sol3, não uma melodia única achatada. Corrija baixo dó3 → si2 e topo sol3 → sol3 repetindo apenas os dois eventos finais até as duas vozes externas chegarem juntas duas vezes. Guarde duas tomadas contínuas de 4 tempos apenas quando C3 → B2 e G3 → G3 alcançarem cada fronteira juntos no registro escrito. Use baixo cantável da inversão como verificação final da passagem pela fundamental.

:::checkpoint Conecte C → G/B três vezes a 66 BPM sem lacuna e depois diga uma voz mantida ou conjunta.

# Conecta C → G/B

Lee C → G/B una vez en la pasada desde la fundamental; el piano mantiene 2 disposiciones durante 4 pulsos, con bajo C3 → B2 y voz superior G3 → G3. Relaciona bajo cantable de la inversión con este principio: El cifrado con barra nombra primero el acorde y después el bajo; las notas entre corchetes empiezan juntas mientras las líneas exteriores revelan dirección. Toca todas las 2 disposiciones a 66 BPM y canta C3 → B2 y G3 → G3 por separado para comprobar bajo cantable de la inversión sin cambiar de registro.

Corrige bajo do3 → si2 y voz superior sol3 → sol3 repitiendo solo los dos eventos finales hasta que ambas voces exteriores lleguen juntas dos veces. Conserva dos tomas continuas de 4 pulsos solo cuando C3 → B2 y G3 → G3 alcancen juntos cada límite en el registro escrito. Usa bajo cantable de la inversión como comprobación final de la pasada desde la fundamental.

:::checkpoint Conecta C → G/B tres veces a 66 BPM sin hueco y después nombra una voz mantenida o conjunta.

# Verbinde C → G/B

Lies C → G/B einmal im grundtonbezogener Durchgang; das Klavier hält 2 Lagen über 4 Schläge, mit Bass C3 → B2 und Oberstimme G3 → G3. Verbinde singbarer Umkehrungsbass mit diesem Prinzip: Ein Slash-Symbol nennt zuerst den Akkord und danach den Bass; Klammernoten beginnen gemeinsam, während die Außenwege Richtung zeigen. Spiele alle 2 Lagen bei 66 BPM und singe C3 → B2 sowie G3 → G3 getrennt, um singbarer Umkehrungsbass ohne Lagenwechsel zu prüfen.

Stelle im grundtonbezogener Durchgang jede notierte Gruppe wieder her und höre gezielt auf Bass C3 → H2 und Oberstimme G3 → G3, nicht auf eine abgeflachte Einzelmelodie. Repariere Bass C3 → H2 und Oberstimme G3 → G3, indem du nur die letzten zwei Ereignisse wiederholst, bis beide Außenstimmen zweimal gemeinsam ankommen. Behalte zwei ununterbrochene Durchgänge über 4 Schläge nur, wenn C3 → B2 und G3 → G3 jede Grenze gemeinsam in der notierten Lage erreichen. Nutze singbarer Umkehrungsbass als letzte Prüfung im grundtonbezogener Durchgang.

# C → G/Bをつなぐ

ルート優先の回でC → G/Bを1回読み、ピアノの2 ボイシングを4 拍保ち、低音C3 → B2と上声G3 → G3を追います。歌える転回形の低音を「スラッシュ表記は先にコード、後に低音を示し、選んだ低音がルート同士を小さく明確な動きでつなぎます」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで2 ボイシングをすべて弾き、音域を変えずC3 → B2とG3 → G3を別々に歌って歌える転回形の低音を確かめます。

ルート優先の回で各記譜グループを戻し、一本の旋律としてではなく、低音ド3→シ2と上声ソ3→ソ3を重点的に聴きます。低音ド3→シ2と上声ソ3→ソ3を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。4 拍を止めずに2回録音し、C3 → B2とG3 → G3が記譜音域の各境界へ同時に着く場合だけ残します。最後にルート優先の回の歌える転回形の低音を確認します。

:::checkpoint C → G/Bを66 BPMで隙間なく3回つなぎ、保った声部または順次進行を一つ言う。

# 连接C → G/B

在根音优先遍中把C → G/B读一遍；钢琴在4 拍内保持2 和弦排列，低音为C3 → B2，顶声部为G3 → G3。把可歌转位低音与“斜线和弦先写和弦、后写低音”这个原理联系起来；方括号内各音同时开始，两条外声路线则揭示方向。以66 BPM弹完2 和弦排列，再保持音区不变，分别唱C3 → B2与G3 → G3来核对可歌转位低音。在根音优先遍中恢复每个写出音组，重点聆听低音do3→si2与顶声部sol3→sol3，不要把和声听成一条被摊平的旋律。

修正低音do3→si2与顶声部sol3→sol3时，只循环最后两个写出事件，直到两条外声连续两次同时到达。不中断地录下两遍4 拍；只有C3 → B2与G3 → G3都在写出音区同时到达每个边界时才保留。先把C → G/B在根音优先遍中完整录一遍，再用可歌转位低音检查第一个边界；只循环修正该处两次，随后回到原速度和音区，不要改动其他事件。最后复核根音优先遍中的可歌转位低音。

:::checkpoint 以66 BPM无间隙连接C → G/B三遍，随后说出一个保持或级进声部。
