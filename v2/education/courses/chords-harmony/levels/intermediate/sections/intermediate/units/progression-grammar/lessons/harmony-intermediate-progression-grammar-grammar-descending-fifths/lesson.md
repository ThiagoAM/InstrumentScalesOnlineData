# iii–vi–ii–V–Iを追う

低音主導の回でiii–vi–ii–V–Iを1回読み、ドをトニックにしたメディアント (iii)–サブメディアント (vi)–スーパートニック (ii)–ドミナント (V)–トニック (I)の5 回の変化を10 拍に収めます。コード進行の構文を「各コードが現在の機能を延ばすか、次の機能を具体的に準備すると進行が明確になります」という原理と結び、再生前に各機能が次の低音ルートへ向くことを予測します。iii vi ii V Iの各コードを2 拍数え、コード進行の構文を基準に5 回の変化を均等にして、V → Iを急ぎません。

低音主導の回で低音ルートを歌い、V → Iを一つの到着として聴いて、最後のコードの機能を言います。低音主導の回で到着の遅れを直すには、V → Iを各コード2 拍で2回反復し、止めずに前の機能を戻します。低音主導の回では、72 BPMで2回弾き、各変化が均等で、V → Iの働きを正答した場合だけ残します。最後に低音主導の回のコード進行の構文を確認します。

# 跟随iii–vi–ii–V–I

在低音主导遍中把iii–vi–ii–V–I读一遍；以do为主音的中音功能 (iii)–下中音功能 (vi)–上主音功能 (ii)–属功能 (V)–主功能 (I)把5 次变化放进10 拍。把和弦进行句法与“当每个和弦延续当前功能或明确准备下一功能时，和弦进行就会清楚”这个原理联系起来；播放前，每个功能都应指向下一个低音根音。iii vi ii V I中的每个和弦都数2 拍；依据和弦进行句法让5 次变化保持等长，不要在V → I处加速。

在低音主导遍中唱出低音根音，再把V → I听成一次到达，并说出最后一个和弦的功能。在低音主导遍中修正迟缓到达时，用每个和弦2 拍的时值循环V → I两次，再不停顿地恢复前面的功能。在低音主导遍中以72 BPM完成两遍；只有每次变化等长并能说明V → I的作用时才保留。最后复核低音主导遍中的和弦进行句法。
