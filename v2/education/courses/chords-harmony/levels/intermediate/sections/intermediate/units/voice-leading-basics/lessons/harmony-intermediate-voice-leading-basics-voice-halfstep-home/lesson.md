# Dm7–G7–Cmaj7を解決する

境界修正の回でDm7–G7–Cmaj7を1回読み、ピアノの3 ボイシングを6 拍保ち、低音D3 → D3 → C3と上声C4 → B3 → B3を追います。声部の無駄のない動きを「滑らかなボイス・リーディングはコードのルート間ではなく、各音が進む距離で考えます」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで3 ボイシングをすべて弾き、音域を変えずD3 → D3 → C3とC4 → B3 → B3を別々に歌って声部の無駄のない動きを確かめます。

境界修正の回で各記譜グループを戻し、一本の旋律としてではなく、低音レ3→ド3と上声シ3→シ3を重点的に聴きます。低音レ3→ド3と上声シ3→シ3を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。6 拍を止めずに2回録音し、D3 → D3 → C3とC4 → B3 → B3が記譜音域の各境界へ同時に着く場合だけ残します。最後に境界修正の回の声部の無駄のない動きを確認します。

# 解决Dm7–G7–Cmaj7

在边界修正遍中把Dm7–G7–Cmaj7读一遍；钢琴在6 拍内保持3 和弦排列，低音为D3 → D3 → C3，顶声部为C4 → B3 → B3。把精简声部移动与“平滑声部进行衡量的是各个音移动的距离，而不是和弦根音之间的距离”这个原理联系起来；方括号内各音同时开始，两条外声路线则揭示方向。以66 BPM弹完3 和弦排列，再保持音区不变，分别唱D3 → D3 → C3与C4 → B3 → B3来核对精简声部移动。

在边界修正遍中恢复每个写出音组，重点聆听低音re3→do3与顶声部si3→si3，不要把和声听成一条被摊平的旋律。修正低音re3→do3与顶声部si3→si3时，只循环最后两个写出事件，直到两条外声连续两次同时到达。不中断地录下两遍6 拍；只有D3 → D3 → C3与C4 → B3 → B3都在写出音区同时到达每个边界时才保留。最后复核边界修正遍中的精简声部移动。
