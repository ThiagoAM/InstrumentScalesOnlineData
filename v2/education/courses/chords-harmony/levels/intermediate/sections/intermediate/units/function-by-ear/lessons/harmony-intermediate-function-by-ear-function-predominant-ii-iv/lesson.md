# ii–IV–Vを聴き分ける

外声優先の回でii–IV–Vを1回読み、ドをトニックにしたスーパートニック (ii)–サブドミナント (IV)–ドミナント (V)の3 回の変化を6 拍に収めます。トニック–プレドミナント–ドミナント機能を「機能は楽句内の役割を示します」という原理と結び、再生前に各機能が次の低音ルートへ向くことを予測します。ii IV Vの各コードを2 拍数え、トニック–プレドミナント–ドミナント機能を基準に3 回の変化を均等にして、IV → Vを急ぎません。
