# vi–ii–V–Iを聴き分ける

再開しないテイクでvi–ii–V–Iを1回読み、ドをトニックにしたサブメディアント (vi)–スーパートニック (ii)–ドミナント (V)–トニック (I)の4 回の変化を8 拍に収めます。トニック–プレドミナント–ドミナント機能を「機能は楽句内の役割を示します」という原理と結び、再生前に各機能が次の低音ルートへ向くことを予測します。vi ii V Iの各コードを2 拍数え、トニック–プレドミナント–ドミナント機能を基準に4 回の変化を均等にして、V → Iを急ぎません。

再開しないテイクで低音ルートを歌い、V → Iを一つの到着として聴いて、最後のコードの機能を言います。再開しないテイクで到着の遅れを直すには、V → Iを各コード2 拍で2回反復し、止めずに前の機能を戻します。再開しないテイクでは、72 BPMで2回弾き、各変化が均等で、V → Iの働きを正答した場合だけ残します。最後に再開しないテイクのトニック–プレドミナント–ドミナント機能を確認します。

在不重启录音中把vi–ii–V–I读一遍；以do为主音的下中音功能 (vi)–上主音功能 (ii)–属功能 (V)–主功能 (I)把4 次变化放进8 拍。把主–下属准备–属功能与“功能描述和弦在乐句中的工作：主功能安定，属前功能准备，属功能把耳朵引向目标”这个原理联系起来；播放前，每个功能都应指向下一个低音根音。vi ii V I中的每个和弦都数2 拍；依据主–下属准备–属功能让4 次变化保持等长，不要在V → I处加速。

在不重启录音中唱出低音根音，再把V → I听成一次到达，并说出最后一个和弦的功能。在不重启录音中修正迟缓到达时，用每个和弦2 拍的时值循环V → I两次，再不停顿地恢复前面的功能。在不重启录音中以72 BPM完成两遍；只有每次变化等长并能说明V → I的作用时才保留。最后复核不重启录音中的主–下属准备–属功能。
