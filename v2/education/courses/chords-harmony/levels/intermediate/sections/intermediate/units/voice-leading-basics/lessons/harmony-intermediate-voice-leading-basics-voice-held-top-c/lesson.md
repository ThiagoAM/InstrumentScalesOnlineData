# Keep held top C: F → C/E → Dm7

Match bass fa3 → re3 with top do4 → do4; begin each bracket together; judge distance between individual voices. Match economical voice motion at 66 BPM; play 3 written voicings, then sing fa3 → re3 below do4 → do4. Hear bass fa3 → re3, top do4 → do4 in the contrast pass, never as one melody; judge small singable voice motion.

# Mantenha C sustentado no topo: F → C/E → Dm7

Leia C sustentado no topo: F → C/E → Dm7 uma vez na passagem de contraste; o piano sustenta 3 aberturas por 6 tempos, com baixo F3 → E3 → D3 e topo C4 → C4 → C4. Relacione movimento econômico das vozes a este princípio: A condução suave mede a distância percorrida por cada nota, não a distância entre as fundamentais; as notas entre colchetes começam juntas enquanto os caminhos externos revelam direção. Toque todas as 3 aberturas a 66 BPM e cante F3 → E3 → D3 e C4 → C4 → C4 separadamente para conferir movimento econômico das vozes sem mudar o registro.

Corrija baixo mi3 → ré3 e topo dó4 → dó4 repetindo apenas os dois eventos finais até as duas vozes externas chegarem juntas duas vezes. Guarde duas tomadas contínuas de 6 tempos apenas quando F3 → E3 → D3 e C4 → C4 → C4 alcançarem cada fronteira juntos no registro escrito. Use movimento econômico das vozes como verificação final da passagem de contraste.

:::checkpoint Sustente a nota comum ou pedal indicada em C sustentado no topo: F → C/E → Dm7; repita três vezes sem reatacar essa voz.

# Mantén C sostenido arriba: F → C/E → Dm7

Lee C sostenido arriba: F → C/E → Dm7 una vez en la pasada de contraste; el piano mantiene 3 disposiciones durante 6 pulsos, con bajo F3 → E3 → D3 y voz superior C4 → C4 → C4. Relaciona movimiento económico de voces con este principio: La conducción suave mide la distancia recorrida por cada nota y no la distancia entre fundamentales; las notas entre corchetes empiezan juntas mientras las líneas exteriores revelan dirección. Toca todas las 3 disposiciones a 66 BPM y canta F3 → E3 → D3 y C4 → C4 → C4 por separado para comprobar movimiento económico de voces sin cambiar de registro.

Corrige bajo mi3 → re3 y voz superior do4 → do4 repitiendo solo los dos eventos finales hasta que ambas voces exteriores lleguen juntas dos veces. Conserva dos tomas continuas de 6 pulsos solo cuando F3 → E3 → D3 y C4 → C4 → C4 alcancen juntos cada límite en el registro escrito. Usa movimiento económico de voces como comprobación final de la pasada de contraste.

:::checkpoint Mantén la nota común o pedal indicada en C sostenido arriba: F → C/E → Dm7; repite tres veces sin volver a atacar esa voz.

# Halte gehaltenes C oben: F → C/E → Dm7

Lies gehaltenes C oben: F → C/E → Dm7 einmal im Kontrastdurchgang; das Klavier hält 3 Lagen über 6 Schläge, mit Bass F3 → E3 → D3 und Oberstimme C4 → C4 → C4. Verbinde sparsame Stimmbewegung mit diesem Prinzip: Glatte Stimmführung misst den Weg einzelner Töne, nicht den Abstand zwischen Akkordgrundtönen; Klammernoten beginnen gemeinsam, während die Außenwege Richtung zeigen. Spiele alle 3 Lagen bei 66 BPM und singe F3 → E3 → D3 sowie C4 → C4 → C4 getrennt, um sparsame Stimmbewegung ohne Lagenwechsel zu prüfen.

Stelle im Kontrastdurchgang jede notierte Gruppe wieder her und höre gezielt auf Bass E3 → D3 und Oberstimme C4 → C4, nicht auf eine abgeflachte Einzelmelodie. Repariere Bass E3 → D3 und Oberstimme C4 → C4, indem du nur die letzten zwei Ereignisse wiederholst, bis beide Außenstimmen zweimal gemeinsam ankommen. Behalte zwei ununterbrochene Durchgänge über 6 Schläge nur, wenn F3 → E3 → D3 und C4 → C4 → C4 jede Grenze gemeinsam in der notierten Lage erreichen. Nutze sparsame Stimmbewegung als letzte Prüfung im Kontrastdurchgang.

:::checkpoint Halte den gemeinsamen oder Pedalton durch gehaltenes C oben: F → C/E → Dm7 und wiederhole dreimal, ohne diese Stimme neu anzuschlagen.

# トップCを保持：F → C/E → Dm7を保つ

対比優先の回でトップCを保持：F → C/E → Dm7を1回読み、ピアノの3 ボイシングを6 拍保ち、低音F3 → E3 → D3と上声C4 → C4 → C4を追います。声部の無駄のない動きを「滑らかなボイス・リーディングはコードのルート間ではなく、各音が進む距離で考えます」と結び、角括弧を同時に始めます。両外声の方向も聴きます。66 BPMで3 ボイシングをすべて弾き、音域を変えずF3 → E3 → D3とC4 → C4 → C4を別々に歌って声部の無駄のない動きを確かめます。

対比優先の回で各記譜グループを戻し、一本の旋律としてではなく、低音ミ3→レ3と上声ド4→ド4を重点的に聴きます。低音ミ3→レ3と上声ド4→ド4を直すため、最後の二つの記譜イベントだけを反復し、両外声を2回同時に到着させます。6 拍を止めずに2回録音し、F3 → E3 → D3とC4 → C4 → C4が記譜音域の各境界へ同時に着く場合だけ残します。最後に対比優先の回の声部の無駄のない動きを確認します。

:::checkpoint トップCを保持：F → C/E → Dm7の指定された共通音またはペダル音を保ち、その声部を弾き直さず3回繰り返す。

# 保持保持顶声部C：F → C/E → Dm7

在对比遍中把保持顶声部C：F → C/E → Dm7读一遍；钢琴在6 拍内保持3 和弦排列，低音为F3 → E3 → D3，顶声部为C4 → C4 → C4。把精简声部移动与“平滑声部进行衡量的是各个音移动的距离，而不是和弦根音之间的距离”这个原理联系起来；方括号内各音同时开始，两条外声路线则揭示方向。以66 BPM弹完3 和弦排列，再保持音区不变，分别唱F3 → E3 → D3与C4 → C4 → C4来核对精简声部移动。

在对比遍中恢复每个写出音组，重点聆听低音mi3→re3与顶声部do4→do4，不要把和声听成一条被摊平的旋律。修正低音mi3→re3与顶声部do4→do4时，只循环最后两个写出事件，直到两条外声连续两次同时到达。不中断地录下两遍6 拍；只有F3 → E3 → D3与C4 → C4 → C4都在写出音区同时到达每个边界时才保留。最后复核对比遍中的精简声部移动。

:::checkpoint 在保持顶声部C：F → C/E → Dm7中保持指定共同音或持续音；重复三遍且不重新起奏该声部。
