# I–IV–V–Iを読む

境界修正の回でI–IV–V–Iを1回読み、ドをトニックにしたトニック (I)–サブドミナント (IV)–ドミナント (V)–トニック (I)の4 回の変化を8 拍に収めます。トニック–プレドミナント–ドミナント機能を「機能は楽句内の役割を示します」という原理と結び、再生前に各機能が次の低音ルートへ向くことを予測します。I IV V Iの各コードを2 拍数え、トニック–プレドミナント–ドミナント機能を基準に4 回の変化を均等にして、V → Iを急ぎません。
