# Shape the Phrase: C major · Reach one clear high point

Put written phrase cell on a steady 99 BPM pulse. Written phrase cell anchors the phrase-shaped target pass with 8 events between 1 and 1. Shape the phrase-shaped target pass through its opening, space, contour, and ending; do not fill every beat. Choose one highest event in written phrase cell; shape the target pass toward it once, then leave enough space for the descent. Use target-release check on the written phrase cell target pass to decide if it sounds like one thought; its rests should feel counted and its ending chosen, not accidental.

Sing the written phrase cell target before the target pass and check its position and duration against playback. If blurred release changes written phrase cell, move to 87 BPM and join the first changed event to its neighbor; rebuild from the opening so the repair belongs to the target pass. Record two target pass takes with written phrase cell at 99 BPM. Accept the phrase-shaped result, named release, when both keep the same opening, intentional rests, and clear ending without extra filler.
