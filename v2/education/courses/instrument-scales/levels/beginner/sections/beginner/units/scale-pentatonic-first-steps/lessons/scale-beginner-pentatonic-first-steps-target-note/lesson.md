# ペンタトニックの第一歩：G メジャーペンタトニック · 特徴音を狙う

目標音の通しでは5音セルの記譜イベントを変えず、次の手順で結果を振り返ります：5音セルの目標音を主音から歌い、カードを弾いて、その音を解放するイベントを答えます。 5音セルで不明瞭な解放が出たら66 BPMに下げ、イベント2から1と直前のアタックを切り出す方法で直し、2回均等になってから全体へ戻します。 5音セルの答えられた解放音は、2回の録音で7イベントの音価を均等に保ち、2から1をつないでGへ明確に終わることなら合格とし、残る誤差を一つ書きます。
