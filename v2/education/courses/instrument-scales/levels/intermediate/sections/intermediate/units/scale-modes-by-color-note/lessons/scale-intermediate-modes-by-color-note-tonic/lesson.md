# 特徴音で聴くモード：ドリアン：ナチュラル6

80 BPMで同主音のモードペアの最初の通しを行い、AをDドリアンの4音、BをDナチュラルマイナーの4音として確認します。 同主音のモードペア・記憶確認：同じ主音とリズムでAとBを交互に鳴らし、最初に異なる音度を歌って、その特徴音で「ドリアン：ナチュラル6」を確かめます。

最初の通しでは同主音のモードペアの記譜イベントを変えず、次の手順で結果を振り返ります：同主音のモードペアを一度弾いたら再生音を消し、記憶だけで反復します。 同主音のモードペアで冒頭と戻りの不一致により誤答したら、68 BPMで両方の主音を歌ってからAとBの全カードを2回交互に鳴らす方法を使い、両方の全カードへ戻します。 同主音のモードペアの一致した冒頭と戻りは、ラベルなしの判定が2回再生と一致し、カードを聴き直さず変わった主音または音集合を言えることなら合格とし、残る誤差を一つ書きます。
