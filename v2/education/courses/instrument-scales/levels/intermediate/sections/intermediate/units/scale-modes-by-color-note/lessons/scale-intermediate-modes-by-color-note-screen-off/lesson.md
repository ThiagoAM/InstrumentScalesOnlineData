# 特徴音で聴くモード：ミクソリディアンとメジャー

75 BPMで同主音のモードペアのテンポの通しを行い、AをFミクソリディアンの7音、BをFメジャーの7音として確認します。 同主音のモードペア・テンポ段階の確認：同じ主音とリズムでAとBを交互に鳴らし、最初に異なる音度を歌って、その特徴音で「ミクソリディアンとメジャー」を確かめます。

テンポの通しでは同主音のモードペアの記譜イベントを変えず、次の手順で結果を振り返ります：同主音のモードペアを記譜された3つのテンポで、同じ動きとタッチを使って弾きます。 同主音のモードペアで不安定なテンポ段階により誤答したら、63 BPMで両方の主音を歌ってからAとBの全カードを2回交互に鳴らす方法を使い、両方の全カードへ戻します。 同主音のモードペアの安定した3段階テンポは、ラベルなしの判定が2回再生と一致し、カードを聴き直さず変わった主音または音集合を言えることなら合格とし、残る誤差を一つ書きます。
