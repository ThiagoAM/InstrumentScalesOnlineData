# メロディックマイナーの地図：Fリディアンドミナント：♯4と♭7

92 BPMで親スケールとモードの比較の折り返しの通しを行い、AをFリディアンドミナントの8音、BをFミクソリディアンの8音として確認します。 親スケールとモードの比較・折り返し確認：FリディアンドミナントとFミクソリディアンを比べ、♭7を保ったまま♯4を分離します。

親スケールとモードの比較の折り返しを切り出し、上行の最後のセルと下降の最初のセルを交互に弾きます。 親スケールとモードの比較で折り返しの隙間により誤答したら、80 BPMでAとBのイベント4だけを4回交互に鳴らす方法を使い、両方の全カードへ戻します。 親スケールとモードの比較の2回の滑らかな折り返しは、ラベルなしの判定が2回再生と一致し、カードを聴き直さずイベント4の変化を言えることなら合格とし、残る誤差を一つ書きます。

# 旋律小调地图：F利底亚属调式：升四级、降七级

母音阶与调式对比的转向检查设为92 BPM，先确认A的F利底亚属调式有8个事件，B的F混合利底亚有8个事件。 在转向检查中用母音阶与调式对比完成这项任务：比较F利底亚属调式与F混合利底亚，在降七级不变时单独听升四级。 为母音阶与调式对比做一次转向核对录音，再查看回放并具体确认两张卡片结束前始终遮住标签，再说出第4个音是A、B的首个差异。

在转向检查中保持母音阶与调式对比的书写事件不变，并按以下步骤复查结果：截取母音阶与调式对比的转向处，交替弹上行最后单元与下行第一个单元。 若转向处的空隙导致母音阶与调式对比判断错误，就以80 BPM只把A、B的事件4交替四次，然后恢复两张完整卡片。 母音阶与调式对比的两次干净转向只有在两次盲选都与播放一致，而且无需重听就能说出事件4的变化时才算完成，并记下下一次仍要修正的第一个具体事件。

:::checkpoint 隐藏标签，在A和B上各完成两次“F利底亚属调式：升四级、降七级”，每次选择或复现都要与播放一致。
