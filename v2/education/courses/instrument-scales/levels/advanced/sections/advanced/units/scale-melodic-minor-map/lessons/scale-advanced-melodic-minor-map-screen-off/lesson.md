# メロディックマイナーの地図：画面を見ずにBオルタードをCへ解決する

72 BPMで親スケールとモードの比較のテンポの通しを行い、AをBオルタードの4音、BをCメロディックマイナーの4音として確認します。 親スケールとモードの比較・テンポ段階の確認：画面を隠し、AのBオルタードの緊張をBの持続するCへ進め、解決が聴こえる位置を答えます。

テンポの通しでは親スケールとモードの比較の記譜イベントを変えず、次の手順で結果を振り返ります：親スケールとモードの比較を記譜された3つのテンポで、同じ動きとタッチを使って弾きます。 親スケールとモードの比較で不安定なテンポ段階により誤答したら、60 BPMでAとBのイベント1だけを4回交互に鳴らす方法を使い、両方の全カードへ戻します。 親スケールとモードの比較の安定した3段階テンポは、ラベルなしの判定が2回再生と一致し、カードを聴き直さずイベント1の変化を言えることなら合格とし、残る誤差を一つ書きます。

# 旋律小调地图：不看屏幕把B变化音阶解决到C

母音阶与调式对比的速度检查设为72 BPM，先确认A的B变化音有4个事件，B的C旋律小调有4个事件。 在速度检查中用母音阶与调式对比完成这项任务：遮住屏幕，把A的B变化音阶张力引到B持续的C，并说出解决开始可听的位置。 为母音阶与调式对比做一次速度阶梯核对录音，再查看回放并具体确认两张卡片结束前始终遮住标签，再说出第1个音是A、B的首个差异。

在速度检查中保持母音阶与调式对比的书写事件不变，并按以下步骤复查结果：母音阶与调式对比按写出的三个速度演奏，保持相同动作与触键。 若不稳定的速度档导致母音阶与调式对比判断错误，就以60 BPM只把A、B的事件1交替四次，然后恢复两张完整卡片。 母音阶与调式对比的稳定的三档速度阶梯只有在两次盲选都与播放一致，而且无需重听就能说出事件1的变化时才算完成，并记下下一次仍要修正的第一个具体事件。

:::checkpoint 隐藏标签，在A和B上各完成两次“不看屏幕把B变化音阶解决到C”，每次选择或复现都要与播放一致。
