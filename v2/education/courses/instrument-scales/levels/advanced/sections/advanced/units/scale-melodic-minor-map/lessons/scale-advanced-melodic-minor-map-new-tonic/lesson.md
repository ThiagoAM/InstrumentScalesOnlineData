# メロディックマイナーの地図：CメロディックマイナーをDへ移す

67 BPMで親スケールとモードの比較の間の通しを行い、AをCメロディックマイナーの6音、BをDメロディックマイナーの6音として確認します。 親スケールとモードの比較・休符後の再入確認：CメロディックマイナーのAを覚え、同じ音度とリズムをBのDメロディックマイナーへ移します。

間の通しでは親スケールとモードの比較の記譜イベントを変えず、次の手順で結果を振り返ります：親スケールとモードの比較の休符中も手を動かして数えます。 親スケールとモードの比較で詰まった無音により誤答したら、55 BPMで両方の主音を歌ってからAとBの全カードを2回交互に鳴らす方法を使い、両方の全カードへ戻します。 親スケールとモードの比較の完全な無音の間は、ラベルなしの判定が2回再生と一致し、カードを聴き直さず変わった主音または音集合を言えることなら合格とし、残る誤差を一つ書きます。

:::checkpoint ラベルを隠してAとBで「CメロディックマイナーをDへ移す」を2回行い、選択または再現をどちらも再生例と一致させる。

# 旋律小调地图：把C旋律小调移到D

母音阶与调式对比的留白检查设为67 BPM，先确认A的C旋律小调有6个事件，B的D旋律小调有6个事件。 在留白检查中用母音阶与调式对比完成这项任务：记住A中的C旋律小调，再把相同音级与节奏移到B中的D旋律小调。 为母音阶与调式对比做一次休止后重入核对录音，再查看回放并具体确认两张卡片结束前始终遮住标签，再说出根音或音集线索。

在留白检查中保持母音阶与调式对比的书写事件不变，并按以下步骤复查结果：母音阶与调式对比的每个休止都继续计数并保持手部动作。 若被挤短的静默导致母音阶与调式对比判断错误，就以55 BPM先唱出两个根音，再把完整的A、B卡片交替两次，然后恢复两张完整卡片。 母音阶与调式对比的完整静默间隔只有在两次盲选都与播放一致，而且无需重听就能说出改变的根音或音集时才算完成，并记下下一次仍要修正的第一个具体事件。
